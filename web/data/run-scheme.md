# Run Scheme v3 · 放置与移动

## 设计锚点

- 烧牌是战略资源，不进常规奖励——对齐杀戮尖塔的烧牌哲学：烧牌是「战略性移除低价值牌」而非惩罚，用移除换取牌库聚焦与即时强度；只在特定机制里以消耗型牌出现
- 战斗差异点：放置物品 + 移动拉扯敌人行动力（反站桩）
- **成长主轴：牌库**；遗物做节点跳变；数值只做小步补间

## 成长节奏

1. **开局**：行前预兆二选一（从 8 枚遗物池抽 2）
2. **前段**：战斗掉牌为主
3. **中点**：已结算 ≥4 房后，下一间非战斗房保底遗物（每局一次）
4. **后段**：难度档靠牌库 + 遗物兑现；曲线末段顶到档 3（Boss 仍为档 5）
5. 静室数值：每次只出 2 项，速度权重更低（防速度滑坡）；残血时治疗保底
6. 恢复：战后喘息 + 静室进门喘息；残血开战有撤退口

## 地形

- **大地图布局（本局伪随机）**：开局按种子在放大画布上生长平面图，再**居中**到 `mapSize`（默认 **17×17**）；房间数约 16–28；拓扑随机：**树 / 网 / 混合 / 主廊 / 翼楼**。邻接导出 **N/E/S/W 门朝向**。**Boss 决战**把本局平面编译成战斗棋盘（一房一格，空洞不可站，只沿门走）。玄关为出生枢纽；祭坛不进随机探索图。种子进存档。关闭：`layoutRoll.enabled=false`
- 行程 `runLength` 默认 12（结算满后开 Boss），地图可比行程更大——不必逛完每一间
- **行程配比（待校准）**：玩家摆房时由类型袋权重约惊吓 40% / 静室 35% / 事件 25%（房卡自带类型）；`layoutRoll.mode=player`。⚠️ 该配比仍不精确，需继续研究山屋架构后再定
- **盖屋**：点开门朝向的「+」空格 → 抽候选 → 旋转门形 → 双边开门才连通；**进房结算才算行程**；可建软边界=`mapSize`
- `walls`：不可通行，阻挡视线
- `heights`：0–2；向上攀爬额外耗体 = 高差（遗物「胶靴」免攀爬费）
- `portals`：成对隧道门；站上不自动传送，玩家点「穿门」/对端格才穿（耗行动力）；敌人寻路把门当边可抄近路；被牌甩上门仍强制传送；落点陷阱可打出「隧道连击」；对端有单位不挡传送（可叠格）
- **单位占格（山屋惊魂式）**：单位不硬挡玩家通路，可与傀儡叠格；**玩家**穿过敌人额外耗 `hostilePassCost`（默认 1）行动力，穿傀儡无额外消耗；**敌人不计穿格税**，寻路不踩玩家格（贴脸攻击），可踩傀儡格并立刻打碎
- 视线：墙遮挡；中间脊（高度 > 双方）遮挡；邻接始终可见
- 无视线：敌方显示 `?`；有 lastSeen 时搜索；丢失目击后改 **巡逻**（随机可达格），不会无限挂机
- 埋伏房：开场可蹲 1 拍；再无目击则下架巡逻（不能躲一辈子）
- 重获视线：突脸
- 高打低：砸物 +1；敌高打你也 +1；你在更高处挨打时略吃地形掩护

## 分房出生（主题埋伏）

- 每间房 `arena.player / enemy / walls / heights` 各自配置，禁止一律左你右怪
- **墙不得整列/整行把玩家与敌人切开**（窄廊尤其容易）；留缝挡视线、留通道能绕
- 开战时若仍无通路，运行时会自动拆掉挡路墙（防死局兜底）
- `ambush: true`：开场无视线时敌人蹲在出生点不搜索，直到建立视线（「铃铛」遗物可揭开）
- `spawnNote`：进战旁白，说明主题（冰箱顶、货架高处、画框后等）
- 开阔房（如客厅、后院）可对峙开场，形成节奏对比
- 已配置传送的房：西厢、长廊、地窖

## 空间连击（布置 × 引怪，不靠力量层）

| 连击名 | 条件 | 效果 |
| --- | --- | --- |
| 追击踩踏 | 本敌回合已移动 ≥1 再踩伤陷阱 | 陷阱伤 +1 |
| 高台砸击 | 你比敌高时砸击 | 砸击 +1 |
| 盐道连击 | 同敌回合先踩盐再踩伤陷阱 | 伤 +1，再削韧 1 |
| 闪瞎连击 | 本场已致盲过，下一次砸击 | 砸击 +2 |

闪光雷致盲：砸中/踩中后敌人 **致盲 1 回合**（清空目击、无法靠视线锁定攻击）；不会因同帧刷新视线立刻恢复。
| 夹击连击 | 砸击时敌邻格有刺/盐 | 伤 +1，削韧 1 |
| 纸影连击 | 追傀儡途中踩伤陷阱 | 伤 +1 |
| 隧道连击 | 传送后落在伤陷阱上 | 喊名（伤已由陷阱结算） |

## 预备（你变成机关）

- 类型 `ready`：点一下挂起，**不占格子**；HUD 显示名称，相邻十字格亮绿边为触发带
- **触发**：仅敌方回合，敌人从「非邻接」走进你正交邻格（突进 / 追击 / 传送落点均算）
- **不触发**：已在邻接站桩砍你；你方回合推撞把它推进邻格
- **同时只能挂一个**；改挂则旧预备落空
- **设计红线**：预备奖励引怪假设，**不否定**敌人行动（不是炉石法术反制）。牌池保持稀少（绷紧 / 迎击 / 甩开）
- **甩开**：敌走进邻接 → 强制位移；**优先邻接刺/盐**，贴脸时也可甩进你**身后**机关；没有机关才推空地；先踩陷阱再传送。与立刻「推撞」分工：你回合布景 / 敌回合喜剧结算
- **贴脸挂预备**：若挂上时已邻接，站桩攻击不触发；须「邻接十字间挪步」或先推开/走开再走进来。沙盒第一敌回合只靠近不下手

## 纸影傀儡（遗物）

- 「预兆·纸影」：每场战斗开局手牌加入 1 张消耗型「纸影傀儡」（占手牌位，开局仍 4 张）
- 放置同地刺（邻格）；场上嘲讽；**挨 1 下才消散**（无回合上限）；场上限 1
- 消耗/临时牌：打出不进弃牌；未打出且未「留」则回合结束清除；点了「留」可例外带到下回合；战斗结束仍清除

## 韧性与机制（压力）

- 共用：**走位引怪踩陷阱 / 盐圈** 削韧；砸击少量削韧（纯追击走路不再削韧）
- 破韧奖励分型：处决 / 装甲 / 踉跄 / 破甲 / 布线（见 `pressure.json`）
- 机制词条（敌人技能）：
  - `lunge` 距 2 真突进：先贴脸再打
  - `faceShock` 重获视线 / 你主动暴露时：贴身惊吓 1；够不着不伤（不再借突脸放全额招）
  - `grab` 命中优先偷手牌药物；无药则扯走杂物
  - `relentless` 目击时攻击更便宜
  - `vault` 优先攀高台再打（吃高打低）
  - `cornerCut` 见面免费抄近一步
  - `trapAware` 寻路避开刺/盐圈
  - `guardBreak` 多耗 1 行动力打出破防，无视格挡与掩体
  - `slam` 须**邻接**砸地：朝向你的 **2×2** AoE（红格）；距 2 站桩不再能砸
  - `beam` 同行/列距 2–4（倾向保持约 4 格）：**1×4 蓄力激光**——隔一回合蓄力、下一拍射出（红格预告）
  - `flurry` 一回合多段攻击（红字写成 `伤害×段数`）；**Boss 不带此词条**
- 埋伏揭开当回合有一次免费扑出（弹簧）
- 已移除：耗体兑换玩家行动力（过肥）
- 追击途中踩陷阱仍 +1 伤；无伤本身就是奖

## Boss 仪式（祭坛）

双轨通关：**熄灭全部信号锚** 或 **打空血条**。播出进度满则失败。

- 祭坛场上 4 枚信号锚（耐久 2）；熄灭方式：站上花 **1** 行动力「拆信号」/ 放置牌砸锚 / **引 Boss 砸地或蓄力覆盖锚点**
- 播出进度上限 **14**：每敌回合推进；有视线额外 +1；熄灭锚点 **-2** / 破韧 **-1** 可减速；「加播」要拆掉 2 锚后才进指令池
- 蓄力大招：先蓄一回合（虚线红格预告），下回合必落；可砸灭锚点
- 阶段：熄灭 1→换台（蓄力变宽）；熄灭 3→终幕（时钟加速）
- 公开节目指令：特写（须先移动再打）/ 点亮舞台（追最近亮锚）/ 静音 / 加播

## 意图预警（格子即信息）

玩家不靠长句心算，看战场格子：

| 视觉 | 含义 |
| --- | --- |
| 红底 + 数字 | 伤害区：回合结束站在这里会挨打 |
| 红底 `2×2` | 多段：每段 2 伤、共 2 段（合计 4） |
| 红底 `2×2→2` | 箭头后是扣掉格挡/掩护的实伤 |
| 蓝虚线框 | 移动区：它下一步可能走到这（不直接伤你） |
| 短标签（突进 2 / 逼近挥击 2 / 追击 / 撕影） | 只点题，细节悬停 banner |

- 意图与结算同源：攻击只打 hurt 区内的你；走开即落空
- **红字包含「走一步再打」**：怪能移动后够到你时，红区提前标出（标签带「逼近」），不会出现「显示追击却挨刀」
- **段数锁定**：敌回合开始时按预告锁定刀数，实际不会超出红字
- 同帧只显示一套主威胁（能打的技能优先于移动脚印）
- 追傀儡时蓝线/撕影指向傀儡格

## 多段攻击（尖塔式明示）

- 默认所有怪 **单段**；只有带 `flurry`「连击」词条的怪一回合打多段（阁楼 / 地窖）
- Boss 多段改由**蓄力大招**承担（红格虚线预告）
- 段数受行动力限制：首段耗 `attackCost`，追加段各耗 1 次攻击费
- 格挡是**池子**：掩体/高差每段都吃，卡牌格挡按实际抵消量扣减，不会一碰就清零
- 不做《山屋惊魂》式的力量拼点：本作对抗靠布置与走位，不再叠第二套骰子对拼系统

## 节奏

> **难度定位**：整体比杀戮尖塔轻松。前期的战斗更像山屋里的力量鉴定类事件——本质是事件延伸，不是独立高压挑战；所有内容最终都服务最后的决战（Boss 仪式）。因此普通房重在「经历 + 成长」，决战的强度与仪式感才是顶点。

- 战斗序号映射难度档：`1→2→2→3→3→3`（`pressure.combatCurve`；第 2 场起抬档，中后段档 3 带伤；Boss 仍固定档 5）
- **Boss 播出窗**：上限 14；熄锚 −2 / 破韧 −1；熄 1 锚后进「换台」时钟 +2（有视线再 +1）。磨蹭拆锚会更快被播映；专注拆锚仍可通，但余量变薄
- **残血减压**：生命 ≤2 时难度档上限 3；生命 =1 时上限 2
- 难度档 3 起伤害 +1（中后段小怪会打疼；Boss / 档 4+ 同）
- 起手生命 6；起手含 1 张「护身符」即时格挡，盐圈仍是走位防御
- **战后喘息**：胜利后若受伤回 1；残血（≤2）回 2
- **静室喘息**：非玄关静室进门若受伤自动回 1；数值池在残血时治疗权重加重且治疗选项保底出现
- **残血进战警告**：生命 ≤2 打开惊吓时间前弹出警告，可「硬闯」或「先撤退」（房间不结算，可改道去静室）
- **任意战斗失败即终局**（清存档 → 结局页 →「再看一集」）；普通战不再「逃出节点」续玩；撤退只发生在开战前警告里

## 敌人行动力与杀意

- 基础行动力 3（Boss 4），档位可再加
- AI：击杀欲 > 生存；有视线追击，无视线搜索；**场上有傀儡时优先追打傀儡**
- 放置：有视线才可砸敌人脚下

# Quaternius animated characters（临时角色精选）

- 作者：Quaternius（@Quaternius）
- 许可：CC0 1.0 Universal；许可摘要保存在 `LICENSE.txt`
- 导入日期：2026-08-15

本目录只保留当前 Godot Demo 使用的两个带骨骼动画 glTF，不提交完整资源包。角色表现通过 `data/presentation_manifest.json` 配置，后续替换正式模型时不需要改动战斗规则。

## 玩家占位模型

- 文件：`Casual_Female.gltf`
- 原包：[Ultimate Animated Character Pack](https://quaternius.com/packs/ultimatedanimatedcharacter.html)
- 原包说明：52 个低模动画角色，提供 FBX、OBJ、Blend 与 glTF 格式，CC0
- 使用动画：`Idle`、`Walk`、`Punch`、`RecieveHit`

## 怪物占位模型

- 文件：`Demon.gltf`
- 原包：[Cute Animated Monsters Pack](https://quaternius.com/packs/cutemonsters.html)
- 原包说明：21 个带动画和纹理的低模怪物，提供 FBX、OBJ、Blend 与 glTF 格式，CC0
- 使用动画：`Idle`、`Walk`、`Bite_InPlace`、`HitRecieve`

这些模型仅作为可替换占位资产，不定义 Lili 或最终怪物的正式造型。

## 0. 产品合并：节目式空间构筑肉鸽 + AI OC（**已锁定**）

**结论（2026-08）**：

- 项目只有一份主策划：`docs/design/织梦频道_channel_dream_策划案与招标书.md`
- 节目式空间构筑肉鸽是唯一主玩法；可构建玩具屋是当集节目布景，不是项目名或传统恐怖山屋主题
- AI OC 是「节目演员 + 局后回顾 + 后台日常 + 长期记忆」功能层
- AI 只能消费确定性事件日志，不得裁定战斗、地图、奖励、胜负或改写存档事实
- 旧 AI OC 独立产品策划全部降为历史参考；冲突时以唯一主策划为准
- 首期固定使用 Lili，验证「事件日志 → 本集回顾 → 记忆碎片」；自由创建、CCv2、多 OC 后移

## 1. 成长主轴：牌库构筑 vs 能力值系统 → 片场工房

**现状**：一集成长仍是牌库（战后选牌 + 遗物跳变 + 静室小数值）。对抗靠放置 × 走位，明确不做山屋惊魂式力量拼点。大地图格子已是房间实例占位（1 / 3 / 5 格共用 `instance_id`）；进战为更细棋盘，按同一 footprint 裁外形。

**倾向口径（2026-08-26，未进主策划、未实现）**：局外成长改为片场工房；角色不走英雄 / 职业菜单。全文见 [片场工房与角色类型](./design/2026-08-26-workshop-and-kits.md)。

- 一整局只有一个祭坛 Boss。时间线是剧情奖励轨（解锁房间零件），不是三幕三个 Boss。
- 局外：时间线发零件 → 地编搭一间装备房 → 开局低权重进入揭格 / 票根池。没搭房也能开一集。
- 抽到自制房：探索更好打、奖励加一档；Boss 对应到该实例时用家具 combo。不加攻击数字。
- 家具优势：站上格子花行动力，用六类场景动词（挡住 / 站上去 / 推开推倒 / 撒一层 / 弄暗弄亮 / 藏进去），复用现有挡格、高差、盐圈、视线。不进牌库，不为每件家具写新卡文。
- 身份：引擎抄尖塔 **2**，卡面抄喵喵定位（在哪 / 怎么挪 / 落点）。移动即防御。少量真格挡，大量道具 / 动作 / 预备。先四套：奇巧、铁甲、故障、亡灵。储君后置。观密作废。
- 明确不做：区域数值光环、局外日历 / 升级金、没搭房不准开局、互动牌进本局牌库、英雄名册、开局职业菜单、把牌身份写成属性轴、开局掷攻击力、先拆专属奖励池、用 1 代观密当第四套、按尖塔每人四五张防御写开局、新卡写成纯数字打击、先做朝向背刺。

**旧候选（搁置）**：A. 面板加点；B. 少量主动技能栏；C. 对抗掷骰（战斗拼点）。均让位于空间构筑。开局掷生命 / 速度 / 手牌不是 C，不视为已否决。

**暂定**：切片继续现行奇巧开局。铁甲 / 故障 / 亡灵开局列表与掷套未写入 `cards.json`。储君未设计开局。工房与家具动词同样先不改正式战斗规则。

## 2. 战斗视野与意图预警

**问题**：无视线时敌人仍在真格显示 `?`，但意图常按「搜索」算、缺少打人红格；对方一回合走位获得视线后攻击，感觉「看得见却没预警」。

**候选**：

1. **见位即预警**（倾向）：格子上标了敌人（含 `?`）就给完整红格  
2. **严格迷雾**：无视线不标真位置，只留 `lastSeen`  
3. **弱化脊挡视线**：墙仍挡；中间高脊不再挡视线  

**暂定**：存疑；未改代码前以现行 `hasLoS` + 意图预告为准。

## 3. 大地图布局伪随机

**已落地**：开局按种子生长连通平面图（玄关固定出生；祭坛/仪式不进随机图）。局内「重开」会弃局并换新种子。

## 5. AI OC 首期实现口径

产品方向已经锁定，以下工程选择仍待原型数据决定：

| 议题 | 当前倾向 | 拍板条件 |
| --- | --- | --- |
| 回顾生成位置 | 异步云端；失败走本地模板 | 测出延迟、单局成本与离线需求 |
| 事件日志字段 | 在 `cabin-lab-v1` 旁新增叙事事件流，不直接拿遥测文本拼 Prompt | 完成 10 局样本并能稳定复述关键事实 |
| 记忆存储 | 先结构化 JSON + 摘要，不先上 ChromaDB | 单角色记忆量超过简单检索能力 |
| 后台日常频率 | 离线最多积累 3 条，不推进主线与数值 | 测试回访期待与内容重复率 |
| 情绪图 | 预设精选立绘；运行时生图后移 | 文字闭环和角色一致性先验收 |
| 玩家数据 | 默认最小采集，可导出/删除，不接外部生活数据 | 完成隐私说明与授权流程 |

在这些议题拍板前，可以实现事件 schema、模板回顾和事实校验；不要提前搭建复杂多 Agent、向量数据库或实时生图管线。

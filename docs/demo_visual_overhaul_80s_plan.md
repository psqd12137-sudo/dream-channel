# 《织梦频道》Demo 80 年代电视包装与移轴摄影方案

状态：第一版视觉系统已接入（2026-08-23）。

## 1. 唯一视觉基准

正式包装以项目作者提供的透明标题图 `E:\doc\channel doc\图层 2.png`、原主页 PV 与 `E:\doc\channel doc\ai\1x` 为准：

- 80 年代儿童电视节目，而不是厚纸板拟物 UI；
- 平面剪纸、几何爆炸框、票根锯齿、粗黑错位投影；
- 高饱和粉、电视蓝、柠檬黄、青绿与暖白；
- 轻微录像带噪声和印刷套色误差；
- 3D 世界仍是黏土/玩具屋微缩布景，UI 是“节目包装层”。

禁止重新引入紫色赛博渐变、传统地牢金属框、写实皮革、厚重纸板浮雕或通用暗黑 RPG UI。

## 2. 色彩与字体

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 墨黑 | `#17151C` | 错位阴影、描边、背景控制台 |
| 节目粉 | `#EE3E91` | 主操作、战斗/异常状态、标题包装 |
| 电视蓝 | `#269DCA` | 次操作、信息模块、爆炸框 |
| 柠檬黄 | `#FFE233` | 奖励、集数、需要注意的信息 |
| 青绿色 | `#12B4AA` | 移动、探索、正常状态 |
| 暖白 | `#FFF3DF` | 票根、正文载体 |

字体分工：

- 展示标题、按钮和短标签：`SmileySans-Oblique.otf`，负责 80 年代节目标题的倾斜和动势；
- 正文、数字、长说明和生僻字：`NotoSansCJKsc-Regular.otf`，保证中文覆盖和小字号可读性；
- 标题图片只用于固定节目字标，不把正文烘焙进 PNG。

## 3. 正式界面包装

### 3.1 标题页

- 保留原有循环视频主页，不用静态标题卡覆盖视频；
- 只将原文字标题替换为作者提供的透明节目字标 `图层 2.png`，运行时使用 1600px 优化副本；
- 操作集中在底部“电视控制台”，避免按钮盖住标题；
- 主按钮用节目粉，教学用电视蓝，继续游戏用青绿；
- 分辨率、窗口模式和移轴开关放在同一画面设置行；
- 开发测试入口继续保留，但视觉上降级且默认收起。

### 3.2 探索与建造

- 房间名、当前/完成状态只进入右侧节目状态栏，不再漂浮在房屋上方；
- 顶栏改为蓝色爆炸框标题 + 粉/蓝套色边；
- 右栏使用暖白票根、青绿侧签和节目电视吉祥物；
- 扩建卡继续保留房型/门位信息，但统一采用粉蓝黄票根语言；
- 导播提示改为底部黑色电视字幕条，左侧节目粉、上缘柠檬黄。

### 3.3 战斗

- 角色血量、敌人意图、行动力和卡牌继续遵守现有安全区与点击契约；
- 所有按钮、标签、提示条由统一绘制函数换皮，因此不改变战斗规则；
- 卡牌类型色保持：放置=黄、预备/异常=粉红、移动/技能=青绿；
- 后续第二轮只替换卡面插画和图标，不再改动已经稳定的手牌动画与命中区域。

### 3.4 奖励、小游戏与弹窗

- 奖励卡、预兆、拼图和打字追逐共享暖白底、粗黑错位阴影和高饱和签条；
- 重要状态用形状和颜色共同表达，避免只靠文字；
- 弹窗背景保持暗色电视演播室，而不是纯黑遮罩。

## 4. 游戏内移轴摄影后效

后效挂在正式游戏的 `WorldContainer`，只处理 3D `SubViewport`：HUD、文字、卡牌和地编工具不受影响。

当前参数：

| 参数 | 默认值 | 说明 |
| --- | ---: | --- |
| 焦带中心 | `0.56` | 聚焦当前房间/战斗棋盘的屏幕纵向区域 |
| 清晰半宽 | `0.18` | 保证角色和交互格仍然清楚 |
| 过渡宽度 | `0.22` | 避免像简单上下遮罩一样突兀 |
| 最大模糊 | `5.5 px` | 建立微缩摄影感，仍保留房间轮廓 |
| 饱和度 | `1.08` | 接近玩具模型摄影 |
| 暗角 | `0.14` | 收拢画面注意力 |
| 胶片颗粒 | `0.012` | 只提供轻微模拟质感 |

实现要求：

- 使用小型九采样核，控制 952×578 视口的成本；
- 关闭时完全回退到原始 3D 画面；
- 开关写入 `user://channel_display.cfg`；
- 不改变镜头投影、玩法格坐标、射线拾取或 HUD 命中区域。

## 5. 分轮验收

第一轮（本次）：视频主页标题层、配色、显示字体、按钮/标签/票根公共组件、房屋浮字移除、移轴开关与后效。

第二轮：逐页截图检查主页、预兆、探索、建造、战斗、奖励、追逐；按 1280×800 基准修正文字溢出和素材比例。

第三轮：用作者原始 PV 的转场节奏补充开播、进房、战斗开始和奖励结算的 6–12 帧包装动画，并加入磁带跳帧音效。

验收线：UI 不遮挡棋盘、卡牌安全区不变、房屋上方无状态字幕、焦带内角色清晰、焦带外模型渐进虚化、所有中文在 1024×640 至 1920×1080 下可读。

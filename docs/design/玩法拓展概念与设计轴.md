# 玩法拓展 · 概念分析（设计轴与多人本质）

> 本文是**概念层**设计文档，不针对具体剧本 / 具体 Boss / 具体胜利条件。
> 目的：回答「玩法的新意到底来自哪里」「多人应该怎么进行」「单机拓展该往哪个方向铺」。
> 素材来源：《山屋惊魂》剧本库 100 个剧本（01–50 已逐一提取胜利条件与规则）。
> 状态：**讨论稿**。与 `cabin-slice/data/multiplayer-haunt-sketch.md`（多人短稿）配套，后者锁方向、本文锁概念。

---

## 1. 核心判断：新意来自哪里

「新意」不在题材（木乃伊 / 鬼魂 / 导演），而在三个结构：

1. **玩家每回合做什么决定**
2. **胜负条件的形状**
3. **信息与压力怎么流动**

一个 Boss 只要换名字换数值、三个结构都不动，玩家就会觉得「和之前一样」。

---

## 2. 五个设计轴

每个轴是一列**可拨动的档位**。拓展 = 把某个轴从当前档位拨向另一档。

### 轴 1 · 胜利路径的形状

**问题**：这一局「怎么算赢 / 怎么算输」？

| 档位 | 含义 |
| --- | --- |
| 歼灭 | 清空对方（线性对抗） |
| 破坏 | 摧毁指定目标物，Boss 守护它 |
| 护送 | 把物品 / 人带到目的地，对方劫掠 |
| 竞速 | 双进度赛跑，先满者胜 |
| 转化 | 把对方变为己方，阵营转移 |
| 仪式 | 完成特定序列 / 组合 |

剧本例证：歼灭 = 召唤凶灵；破坏 = 死亡舞曲；护送 = 木乃伊；竞速 = 众星就位；转化 = 月夜人狼；仪式 = 长埋地下。

**织梦频道现状**：歼灭 + 破坏（打血 / 熄锚）。

### 轴 2 · 敌人的可及性

**问题**：你能怎样「赢过」它？

| 档位 | 含义 |
| --- | --- |
| 直接击杀 | 打空血条 |
| 命门 | 需特定道具 / 条件才能伤 |
| 不可击杀 | 只能拖 / 躲 / 绕 |
| 非击杀路径 | 击杀不是主要解法 |

剧本例证：龙潭死斗（无甲不能伤）；蛙腿炖菜（幻影先解）；乌洛波洛斯（蛇头无敌）。

**织梦频道现状**：直接击杀（Boss 也能被打血）。

### 轴 3 · 空间的角色

**问题**：地图是干什么用的？

| 档位 | 含义 |
| --- | --- |
| 战场 | 对峙与连击的舞台 |
| 掩体网 | 视线 / 藏匿 / 高低差结构 |
| 路径网 | 跑酷 / 护送 / 追逐通道 |
| 环境机关 | 地图本身是武器（可动 / 可毁 / 可重排） |
| 尺度 | 单房 ↔ 多区 ↔ 整图 |

剧本例证：棋盘死局（对弈棋盘）；迷失空间（重洗地图）；触目惊心（电梯瘫痪）。

**织梦频道现状**：战场（单房 4×5），弱掩体（墙 / 高差）。

### 轴 4 · 信息结构

**问题**：谁知道什么？

| 档位 | 含义 |
| --- | --- |
| 全信息 | 彼此可见 |
| 视线遮挡 | 墙挡 LoS，转角遭遇 |
| 敌寻我 | 玩家躲藏，Boss 扫视 / 追踪 |
| 我隐敌 | 隐形 / 误导 / 假目标 |
| 欺骗 | 诱饵 / 假信息 |

剧本例证：鬼抓人（躲藏被找）；隐形人魔（隐形追踪）；催命女妖（无实体）。

**织梦频道现状**：视线遮挡（LoS 已有），其余空缺。

### 轴 5 · 压力来源

**问题**：是什么在逼你动？

| 档位 | 含义 |
| --- | --- |
| 敌数量 | 多单位围堵 |
| 敌强度 | 单体高压 |
| 倒计时 | 回合 / 进度限制 |
| 状态累积 | 污染 / 标记 / 被转化累积 |
| 资源损耗 | 道具 / 体力 / 场地被蚕食 |

剧本例证：猫的时间（数量）；日出之前（倒计时）；阴尸路（感染累积）；鸿门夜宴（吃尸体强化）。

**织梦频道现状**：敌强度 + 倒计时（播出进度）。

## 3. 织梦频道在轴上的占位与缺口

| 轴 | 现状 | 缺口 |
| --- | --- | --- |
| 轴1 胜利路径 | 歼灭 + 破坏（打血 / 熄锚） | 护送 / 竞速 / 转化 / 仪式 |
| 轴2 可及性 | 直接击杀 | 命门 / 不可击杀 / 非击杀路径 |
| 轴3 空间角色 | 单房战场（弱掩体） | 多区尺度 / 路径网 / 环境机关 |
| 轴4 信息结构 | 视线遮挡 | 敌寻我 / 我隐敌 / 欺骗 |
| 轴5 压力来源 | 敌强度 + 倒计时 | 数量 / 状态累积 / 资源损耗 |

## 4. 玩法类型速查（从剧本库提炼，供选档时参考）

> 这些是「主题标签」不是概念。真正驱动玩法的是上面的轴；下表只用来在讨论时快速指认「哪个剧本属于哪类」。

| 类型 | 核心 | 对应轴档位 |
| --- | --- | --- |
| 转化 / 感染 | Boss 把对方变成自己人，阵营转移 | 轴1·转化 + 轴5·状态累积 |
| 收集 / 护送 | 集齐 N 件物品带到指定点 | 轴1·护送 + 轴3·路径网 |
| 竞速 / 倒计时 | 双进度赛跑，先满者胜 | 轴1·竞速 + 轴5·倒计时 |
| 目标破坏 / 命门 | 破坏目标物 / 需道具才能伤 | 轴1·破坏 + 轴2·命门 |
| 潜行 / 躲藏 | 敌人来找你，被发现 = 危险累积 | 轴4·敌寻我 + 轴5·状态累积 |
| 召唤 / 围堵 | 本体不强，不断召小怪 | 轴5·数量 |
| 规则反转 | Boss 无法直接打死，靠特殊条件 | 轴2·不可击杀 |
| 地形操纵 | 地图本身是武器 | 轴3·环境机关 |

## 5. 多人「怎么进行」的概念本质

多人短稿锁定的流程：**分头探索 → 半场奸徒 → 整图终局分工**。

把它翻译成概念，是三个东西的引入：

| 多人骨架 | 概念本质 | 依赖轴 |
| --- | --- | --- |
| 分头探索 | **信息不对称**的放大——各人只见局部 | 轴4 信息结构 |
| 半场奸徒 | **目标不对称**的引入——有人目标翻面 | 轴1 胜利路径 |
| 终局分工（拖怪 / 跑酷 / 破机关） | **空间分工**的极限——各人承担不同空间职责 | 轴3 空间角色 + 轴2 可及性 |

关键结论：多人终局强依赖 **轴3（空间分工）** 与 **轴4（信息结构）**。

## 6. 概念结论：拓展顺序

单机 Boss 战拓展的核心不是「换胜利条件」（轴1），而是先让：

1. **轴3** 从「单房战场」拨向「多区 / 路径网」——先给空间分工载体
2. **轴4** 从「视线遮挡」拨向「敌寻我 / 欺骗」——先给拖怪 / 跑酷 / 藏匿的信息条件
3. **轴1** 胜利条件（护送 / 竞速 / 转化）在这个载体上才有意义

反过来说，只拨轴1（换胜利条件）而地图仍是单房，分工循环长不出来——这就是「新 Boss 让人感觉和之前一样」的结构性原因。

## 7. 参考系拆解：山屋惊魂 × 杀戮尖塔 × 以撒的结合

常被问「channel 是不是 = 山屋惊魂 + 杀戮尖塔 + 以撒的结合」。这个类比**方向准确，但三者的贡献层不同，完成度也不同**：

| 参照 | 贡献的层 | 借到什么 | 目前完成度 |
| --- | --- | --- | --- |
| 山屋惊魂 | **流程骨架** | 探屋、预兆、半场奸徒、拖怪 + 破机关 | 借到一半：探屋 / 预兆已落地；奸徒、整图终局未落地 |
| 杀戮尖塔 | **单局循环** | 一局构筑、节点节奏、失败重来 | **最实**：行程节点、战后选牌、遗物、Boss 双轨全部落地 |
| 以撒的结合 | **空间战斗** | 房间战、物品组合、走位而非站桩 | 借得最轻：有走位 / 放置 / 高低差，但没有以撒式的空间即时性（我们是回合制） |

**精确说法**：山屋惊魂的流程骨架 × 杀戮尖塔的构筑循环 × 以撒的「空间化战斗」——但目前三者完成度是 **杀戮尖塔 ≫ 山屋惊魂 > 以撒的结合**。

其中「以撒」贡献的不是弹幕，而是「**让战斗发生在空间里**」——这正对应轴3（空间角色）与轴4（信息结构）的缺口。Boss 战从单房铺向整图多区后，这个「空间味」才会真正长出来。

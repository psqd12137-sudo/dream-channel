# 片场工房与角色类型

状态：未决讨论（2026-08-26）。尚未写入主策划，也尚未改 Godot / `cards.json`。登记见 [未决设计 §1](../open-questions.md)。

今天讨论的两块放在这里：局外怎么养一间房；一集里角色和卡怎么定。根 README 只导航，不存正文。

## 1. 局外片场与房间构筑

现行一集仍以牌库 + 预兆 + 静室为成长；切片不要提前拆牌库。

一整局只有一个祭坛 Boss，不做成杀戮尖塔式三幕三个 Boss。要借的是尖塔那种「越玩越揭开内容」的剧情奖励轨：打过的节点把房间零件发进工房，不在一集里加第 2、第 3 个 Boss。

局外只做三件事：

1. **节目时间线**（账号进度）：节点是「第一次惊吓」「第一次抽到自制房」「第一次通关」等剧情奖励，发给工房的是家具、门、墙和 1 / 3 / 5 格形状。先解锁 1 格零件，再 3 格，再 5 格，避免自制五格开局压过种子精英房。
2. **工房**：沿用现有房间地编（`asset_editor_3d`）。用已解锁零件搭一间装备房并勾选装备。没搭过房也能开一集。
3. **装备进图**：开局把装备房以低权重放进揭格 / 票根池。抽中则按现行 `room_rules` 生成房间实例（`source=player_template`），占地和对门规则不变。没抽中则本集没有私有主场，祭坛照打。

大地图格子已经是房间实例的占位（1 / 3 / 5 格共用 `instance_id`，进任一格只结算一次）。进战仍是更细的棋盘，再用同一 footprint 裁外形。抽到自制房时：探索更好打、奖励加一档（多一张候选或时间线多跳一格）。唯一 Boss 若对应到这一实例，用这间房的家具打 combo。优势是作者知识和走位，不是攻击数字。

房间构筑如何变强（直觉、不新开卡池）：

- 可互动家具钉在战场一格。站上该格、花本回合行动力，才能用它。走开提示收回。不进牌库、不进本局奖励池。
- 工房只给家具勾一类场景动词，全部复用现有规则，不为每件家具写卡文：**挡住**（blocker）、**站上去**（H1 高差）、**推开 / 推倒**（改通行，倒地可按地刺结算）、**撒一层**（盐圈）、**弄暗 / 弄亮**（视线或闪瞎）、**藏进去**（这格暂时不算被看见）。
- 种子房先只用挡住和站上去，用来教会规则。自制房才把其余动词排成玩家记得的一条线。
- 不做区域攻击 / 生命光环，不做局外日历和升级金。抽屉、箱子最多本场入手一张临时牌。

多人暂按杀戮尖塔式同图：各人一条时间线、一间装备房；半场奸徒后置。旧短稿里「一房一格」指大地图行程节点，不删 1 / 3 / 5 内部与家具动词。自制房是地形，不是角色类型。

## 2. 角色类型与卡牌

一个演员，开局掷套。引擎抄杀戮尖塔 2，卡面抄喵喵的结合的定位。移动即防御。玩家读牌像读猫，自己判断这局怎么用。卡面上不印职业。

### 2.1 作废

- 刺 / 盐 / 预备 / 视线 / 路 / 影当能力轴。那些是牌和家具动词，不是角色数值。
- 1 代观密者当第四套职业。杀戮尖塔 2 是铁甲、猎手、储君、亡灵缚师、故障。
- 按尖塔每人四五张防御写开局。织梦走开红区就是防。盐圈是道具，不是防御牌。护身符才是真格挡，整套只留少量。
- 选人界面、英雄名册、开局职业菜单、专属奖励池、新卡写成「造成 X 伤」、先做朝向 / 背刺。

### 2.2 卡牌四类（量）

| 种类 | 现有 type | 干什么 | 量 |
| --- | --- | --- | --- |
| 道具 | place | 丢到格子上：地刺、盐圈、闪光、纸影、凿钉、落锤 | 大量 |
| 动作 | skill | 立刻做一件事：推撞、登台、崩裂、屏息 | 大量 |
| 预备动作 | ready | 挂上，等它走进来：绷紧、迎击、甩开 | 大量 |
| 防御 | 真格挡 | 护身符这种点一下给格挡 | 少量 |

药物（补剂、肾上腺素）另算，也少。预备里带一点格挡（绷紧）仍算预备动作，不算防御牌。

### 2.3 卡面怎么写

泡泡堂负责把道具丢到格上，喵喵负责站位、推拉和落点。尖塔 2 只负责牌组引擎，不负责卡怎么说话。

| 卡要写清 | 用现有规则 | 不要写成 |
| --- | --- | --- |
| 在哪：邻格、脚下、身后、更高处、传送落点 | 放置邻格、砸脚下、登台、穿门 | 造成 2 伤。 |
| 站位怎么变：推、甩、引、换格 | 推撞、甩开、引渡 | 获得 2 力量。 |
| 落点怎么算：踩刺、进盐、撞墙、穿门、高打低 | 落点触发、盐道连击、隧道连击 | 造成 6 点伤害。 |
| 什么时候：你丢出去 / 它走进来 | 道具踩上结算、预备走进十字 | 本回合攻击两次。 |

| 已经像喵喵 | 更像尖塔引擎（可以少留，不当脸） |
| --- | --- |
| 推撞：邻接推 1 格，落点优先机关 | 护身符：立刻 2 格挡 |
| 甩开：它走进来，甩进刺 / 盐 | 屏息 / 预案 / 夹带：费用和留牌 |
| 落锤：你比它高，砸击加伤 | 崩裂：削韧、抽牌、减费 |
| 隙刺：刚穿门落到这格再加伤 | 补剂：行动力 +2 |

新卡优先第一种。一套偏向的身份牌必须是定位牌。

### 2.5 四套开局（各 10 张）

**奇巧 · 猎手（已在跑）**  
`jab ×3 · guard ×3 · flare · focus · tonic · keepsake`  
7 张道具、1 动作、1 药、1 防御。盐圈算道具。

**铁甲**  
`jab ×3 · chisel · drop_hammer · heavy · shove · rupture · adrenaline · tonic`  
6 道具、2 动作、2 药、0 防御。

**故障**  
`jab ×2 · guard ×3 · warp_trap · snare · plans · stash · tonic`  
7 道具、2 动作、1 药、0 防御。

**亡灵**  
`jab ×2 · decoy · chisel · guard · brace · riposte · fling · shove · tonic`  
5 道具、1 动作、3 预备、1 药、0 防御。

储君后置：2 代要同时管能量和星辰，织梦现在只有行动力。

### 2.6 仍然不抄尖塔的部分

| 2 代还有什么 | 这次做 | 这次不做 |
| --- | --- | --- |
| 五人选人 | 掷中一套，仍是莉莉 | 选人、HUD 职业名 |
| 每人四五张防御 | 移动即防御；真格挡少量 | 按尖塔比例写开局 |
| 每人专属卡池 | 奖励池共用；继续堆道具 / 动作 / 预备 | 按偏向过滤三选一 |
| 观密姿态 | 预备动作是卡种类，不是第四套职业 | 整套观密作废 |

## 3. 切片

现行客户端只有奇巧开局。铁甲 / 故障 / 亡灵列表、开局掷套、工房进图、家具动词均未实现。敌方 hunter / flanker 只给 AI 用。

## 0. 一句话与电梯稿

**一句话**  
玩家带着官方角色或自己的 OC 拧开一台邪典儿童节目的电视机，成为会失控的微缩玩具秀演员：在会咬人的纸盒布景里用**放置道具 + 走位拉扯**打怪；每局经历都会成为角色记得、讲得出来的一集节目。

**电梯稿（30 秒）**  
channel 是一档用纸盒、黏土、毛毡和涂漆玩具搭出来的怀旧儿童秀。现实玩具投射进电视中的梦，玩家共同搭建、探索、构筑与战斗，享受小玩法和互动制造的欢乐。三阶段中，梦逐渐混乱，合作事件开始夹杂对抗与被迫误伤；玩家的表现和信物投入累计为演出成绩，也为剧本提供素材。第三阶段末尾，节目以隆重而邪恶的颁奖仪式展开最终 Boss 破坏秀，将共同积累的一切变成高潮。梦最终醒来，角色重新成为静止玩具，留下经历与新玩具的解锁机会。AI 仅表达真实经历与记忆。当前单机原型和多人设计的完成状态分别记录，不把设计方向视为联机已实现。

### 0.1 现实玩具与电视梦境（2026-09-10 已确认方向）

现实中的角色玩具、房间地块和物品是长期拥有的载体；玩家在现实中进行有物理意义的拼装。睡着的主角将这些玩具与房间投射进电视，成为一集节目，局内扩建、构筑与战斗发生在超现实的梦境里。

玩家操控的玩具承载主角对娱乐的需求。每次翻地块和游玩都会使梦境松动；敌人与 Boss 是试图提前终结梦境的监管力量。梦一定会醒，玩家争取让梦做到该醒的时候。结尾角色必然失去活力，重新成为玩具；漂亮的棋盘、精妙的战斗、史诗级演出与梦碎的遗憾共同构成重玩动机。

精彩演出可带来解锁，通过电视节目订购角色、房间地块等内容，并获得可在现实中持有、拼装的载体，再投射进下一场梦。“精彩”的判定、订购费用、失败收益、松动数值、三阶段门槛和胜负差别尚未锁定。节目制作任务、三个 Boss、固定 12 房彩排流程均不因本方向自动成立。

完整总结见 [现实玩具、电视梦境与节目循环](./2026-09-10-现实玩具与电视梦境.md)。该专题展开本节；未决机制见 [未决设计](../open-questions.md)。以下既有玩法、AI OC 与里程碑条目仍保留各自原有状态，其中局外日常与静止玩具的世界观衔接需后续统一。本节不声明新循环已经实现。

## 1. 产品定位

### 1.1 我们是什么

| 维度 | 定义 |
| --- | --- |
| 品类 | 邪典荒诞儿童玩具秀题材的 **空间构筑 roguelike / 节目流程游戏** |
| 单机核心 | 房间探索 + **放置 × 走位** + 牌库成长；三阶段信物投入与剧本抽选，第三阶段末尾进入 PvE 破坏秀；无虚拟参赛者或反派选角 |
| 角色层 | 官方角色或玩家 OC 作为「节目演员」；局后形成回顾、关系与记忆 |
| 产品结构 | **肉鸽玩法是主干，AI OC 是局外情感与叙事层**；两者共享同一角色、事件日志和频道包装 |
| 多人方向 | 三阶段：合作玩耍 → 混乱与对抗增加 → 第三阶段末尾颁奖选角与 Boss 破坏秀；细则见第 6 节 |

### 1.2 我们不是什么（硬否决）

| 明确不做（主线） | 原因 |
| --- | --- |
| 搜打撤 | 核心是演出与欢乐，不引入先撤后撤、携物撤离和撤离经济作为主循环 |
| 脱离共同梦境的小游戏堆砌 | 允许借鉴马里奥派对的小玩法与评分颁奖；事件应服务共同经历、阶段变化和最终演出 |
| 狼人杀 / 开局隐身份投票局 | 反派出演由演出成绩结算与终幕规则组织，不以嘴炮验人、投票放逐为主循环 |
| 纯站桩数值卡牌 | 移动与放置是战斗身份 |
| 第二套独立战斗养成轴 | 小玩法可贡献演出成绩；选角评分不自动转化为另一套战斗属性成长 |
| 一上来做完整联机运营 | 先单机一集验证节目感 |
| 独立的 AI 陪伴/聊天 App | AI OC 必须消费肉鸽真实经历，不能再分裂成另一款产品 |
| AI 裁定战斗、奖励或存档事实 | 玩法结果必须由确定性规则产生，AI 只负责演绎和表达 |

## 2. 体验支柱（设计验收用）

任何功能上线前问这六句；答不上来就砍或降级。

1. **节目感**：这像不像「频道里播出的一集」，而不只是规则表？  
2. **空间感**：玩家是否在用房间、墙、视线、高低思考，而不是只算 DPS？  
3. **反站桩**：移动与放置是否比正面硬刚更优？  
4. **欢乐与参与**：事件是否制造有趣的互动、回应和演出，而非无关小游戏或验人流程？
5. **可惨不死**：多人方向倾向 Boss 战前不直接死亡，让受伤和事故继续形成经历；具体倒地、恢复与 Boss 失败边界待验证，旧单机战败规则不视为已修改。
6. **角色记得**：本局是否留下了可回顾的角色经历，而不是打完即清零？

## 3. 单机主循环

### 3.0 三阶段剧本抽选（2026-09-10 已确认设计方向）

单人模式只由玩家参与。“竞拍”指向节目投入素材、影响本局走什么剧本，不模拟其他参赛者，不设置竞价对手、排名竞争或最终反派出演资格。此前提出的“两名玩具嘉宾参赛”方案不采用。

| 阶段 | 玩家选择与探索 | 阶段结果 |
| --- | --- | --- |
| 第一阶段 | 以局外自建房入场，探索并获得自己配置牌组的机会；可以弃权 | 从自己实际走过的地块中抽取第一份剧本素材，投入只影响概率，不锁定结局 |
| 第二阶段 | 继续探索、构筑、游玩，选择投入信物或弃权 | 结合地块经历与受伤区域权重倾向，抽取第二份素材 |
| 第三阶段 | 最后一次信物投入或弃权，完成本阶段素材抽选 | 三份素材组合为终幕剧本；第三阶段末尾直接进入颁奖式 PvE 破坏秀，不增加第四阶段 |

弃权仍从自己走过的房间抽选；单人只有一个投注者，也不能使投入必然成为结局。候选池、概率和素材组合的具体算法待验证，尤其需处理候选过少的情况。房间局内一次性、不重复，自制房采用万能房随时放置还是卡堆随机获得仍未定。

信物的稀有度和难度仍可贡献演出评分。单人评分用于记录表现，具体奖励用途未定；不设置出演排名，也不默认将总评分转换为剧本命中率。素材投入对抽选的影响与演出评分分别定义，避免把两者混成一个数值。

玩家即使在剧情上成为反派，仍是单人 PvE：身份可以改变目标与演出，不产生奸徒阵营或额外参赛者。具体“玩家负责破坏、系统单位阻止”等内容属于候选剧本，不视为已锁定机制。

第 6 节的三阶段素材与房间规则可复用于单人，但合作误伤、排名颁奖和反派选角仅适用于多人。以下 3.1—3.5 保留旧单机原型基线，不表示本节新方向已经实现；新方向的阶段房数、评分、权重及胜负规则另行验证。

### 3.1 一局结构

```text
行前预兆二选一
  → 雾图探索（约 10 房行程）
  → 惊吓房：放置×走位战斗 / 静室：成长或考验
  → 祭坛 Boss（仪式双轨）
  → 通关或被播映/战死
```

### 3.2 战斗身份（不可动摇）

- **出牌 = 往场地放物品**（地刺、盐圈、闪光等）或打出即时技巧/药物  
- **移动**迫使敌人把行动力花在追击上  
- **韧性**：走位引怪踩机关削韧 → 破韧分型奖励 → 再输出  
- **意图看格子**：红区伤害、蓝虚线移动；玩家不靠长句心算  
- 地形：墙挡视线、高低差、传送格、埋伏、突脸  

细则见仓库：`cabin-slice/data/run-scheme.md`、`cards-rules.md`、`pressure.json`。

### 3.3 成长

- **主轴：牌库**（战斗胜利加牌）  
- **跳变：遗物节点**（开局二选一、中点保底）  
- **辅：静室小数值**（速度权重低）  
- 不做局外长养成阻塞一局体验  

### 3.4 节奏目标混合（可调）

| 类型 | 约占比 | 作用 |
| --- | --- | --- |
| 惊吓战斗 | 40% | 主循环 |
| 静室数值/预兆 | 35% | 喘息与成长 |
| 解密·视角事件 | 25% | Haunt 式考验，调剂操作通道 |

当前问题：静室多为弹窗二选一——**配比已靠 40/35/25 落地，下一期继续打磨静室呈现与 Boss 曲线。**

### 3.5 事件考验（克制）

原则：短、好懂、有趣；允许年代记忆玩具感；**全图少量挂载**。

| 类型 | 状态 | 说明 |
| --- | --- | --- |
| QTE 跟键 | 已接占位（泥靴间） | 有金山打字憨感；失败丢奖励，血>1 可 −1 |
| 八数码拼图 | 未做 | 滑块还原，限步/限时 |
| 第二视角搜物 | 未做（仅临时 2D WASD 沙盒） | **最终：3D 微缩景深**，非扁横版平台跳 |
| 打字追逐 PvP | 愿景旁支 | 不进节目主线 |

## 4. AI OC：节目演员与局外记忆层

### 4.1 功能定位

AI OC 不是第二套主玩法，而是把一局肉鸽从「一次规则结算」变成「这个角色亲历的一集节目」。

| 对象 | 权限与职责 |
| --- | --- |
| 玩家 | 创建/选择 OC，决定核心设定，在战斗和探索中直接操作角色 |
| 确定性游戏系统 | 决定地图、行动、伤害、奖励、胜负与存档，是事实唯一来源 |
| AI 演员层 | 根据事实日志生成角色口吻、局后回顾、后台日常和记忆呼应 |
| OC | 既是局内可控角色，也是局外会回忆、评论并被经历塑造的节目演员 |

当前竖切片先使用官方角色 **Lili** 验证整条链路；自建 OC、导入角色卡和多 OC 关系不进入首个 MVP。

### 4.2 合并后的完整循环

```text
选择官方角色 / OC
  → 进入节目式空间构筑肉鸽（玩家直接操作，规则确定性结算）
  → 记录房间、受伤、连击、遗物、Boss、胜负等事实
  → 生成「本集回顾」与角色短评
  → 关键事实沉淀为角色记忆
  → 后台 / 离线生活片段引用这些记忆
  → 下一局在台词、反应和节目包装中形成呼应
```

AI 内容必须依赖真实局内事件。没有发生过的胜利、同伴、道具或关系变化不得被生成器补写。

### 4.3 首期功能

| 功能 | 首期口径 | 明确不做 |
| --- | --- | --- |
| 本集回顾 | 用现有 `cabin-lab-v1` 与事件日志生成 3～6 句节目摘要 | 自由编造另一段冒险 |
| 角色短评 | Lili 以稳定人设评论本局高光、失误或失败 | 无限制聊天 |
| 记忆碎片 | 每局提取 1～3 条结构化记忆，可由玩家标记重要 | 把完整聊天记录全部塞进上下文 |
| 后台日常 | 离线期间最多积累 3 条、每条 2～4 句，只延续最近节目余波 | 离线推进主线、发奖励或改变战斗状态 |
| 情绪表现 | 先使用人工精选的预设情绪立绘和短动画 | 每段文本实时生图 |
| 回顾空间 | 按节目期数查看事实、回顾文本和角色记忆 | 删除玩家可见的历史记录 |

### 4.4 记忆规则

| 层级 | 内容 | 衰减规则 |
| --- | --- | --- |
| 核心设定 | 名称、外观、性格底色、背景、禁止行为 | 永不由 AI 修改 |
| 重要记忆 | 首次通关、关键 Boss、玩家手动标记事件 | 长期保留并可导出 |
| 经历记忆 | 普通房间、受伤、卡牌连击、节目事故 | 检索权重随时间与引用次数下降 |
| 回顾档案 | 每局完整事实日志与已生成回顾 | 玩家始终可查看；不因 AI「遗忘」而删除 |

「记忆的自然死亡」只表示旧经历逐渐不再进入 AI 上下文，不表示篡改存档或向玩家收费赎回记忆。角色可以遗忘细节，项目不能删除玩家的历史。

### 4.5 AI 边界与质量门槛

1. **规则不交给 AI**：战斗、地图、奖励、数值、胜负和成就只读游戏状态。
2. **玩家拥有角色**：核心设定不可擅改；角色资料、重要记忆和回顾支持导出。
3. **事实先于文采**：生成前传入结构化事件，生成后校验角色名、Boss、结果和关键数值。
4. **失败可降级**：超时、限流、审核失败时使用模板回顾，不阻塞结算和开下一局。
5. **内容要克制**：检测 OOC、事实矛盾、近期开场/情绪/措辞重复；最多重试两次。
6. **隐私默认最小化**：首期不读取通讯录、日历、健康数据，不向外部聊天软件主动发消息。

首期采用一条可观测流水线，不为“多 Agent”而拆 Agent：

```text
确定性事件日志
  → 回顾生成器
  → 人设 / 事实 / 重复 / 安全校验
  → 结构化记忆提取
  → 回顾空间与后续检索
```

### 4.6 分期

| 阶段 | 交付 |
| --- | --- |
| A：网页验证 | Lili 固定人设；本集回顾；1～3 条记忆；模板降级；不做运行时生图 |
| B：单机样片 | 回顾空间；后台日常；情绪立绘；本地/云端模型适配；角色数据导出 |
| C：内容扩写 | 自建 OC、微习惯、CCv2 导入导出、多角色槽位 |
| D：多人之后 | 队友共同记忆、分头经历拼接、奸徒事件的有限视角回顾 |

**验收**：回顾不得与战局事实矛盾；陌生玩家能从语气辨认 Lili；下一局能自然引用旧经历；关闭 AI 服务后肉鸽仍可完整游玩。

## 5. 美学与视听规格

### 5.1 视觉

- **关键词**：黏土/毡质角色、玩具屋、浅景深、盒中景、CRT/儿童节目包装  
- **第二视角/展示房**：3D 微缩 + 景深（路易吉鬼屋 / DQ7 重置向）  
- **UI**：可保留「节目单/票根/嘴巴电视机」等邪典儿童节目符号（现网页已有雏形）  
- **房屋身份**：可构建房屋是儿童节目摄影棚中的实体微缩布景；允许露出胶带、接缝、支架、轮子、场记标和假透视
- **禁止**：默认紫渐变赛博无风格堆砌；把 channel 做成通用黑暗魂 UI、传统地牢或纯温馨住宅

#### 5.1.1 房间资产与角色占位锁

房间首先要让人相信角色可以生活和互动，其次必须让人意识到这是一套正在播出的玩具秀布景。每个房间的表现层按以下结构验收：

| 层 | 规则 |
| --- | --- |
| 宜居主体 | 床、桌、椅、柜、炉具等建立明确房型；借鉴 `Virtual Cottage 2` 的构图密度，不复制其主题 |
| 节目证据 | 每房至少一处场记板、走位胶带、摄影灯、提词卡、假窗、布景支架或可见机关 |
| 荒诞破口 | 每房保留一处可被事件激活的错误比例、重复道具、异常动作、串台声画或不合时宜文案 |
| 制造语言 | 纸板高粗糙度，黏土/毛毡保留手作起伏，涂漆木件允许磨损；避免写实 PBR 豪宅和通用地牢石材成为主印象 |
| 演员走位点 | 一个逻辑格可拥有多个家具交互槽；坐、靠、翻找、表演、躲藏分别占槽，多人不得争用同一槽 |
| PCG 边界 | 家具和节目装置属于表现层，不改门洞、连接边、寻路和战斗账本；门、楼梯、开放通道与建造接口必须保留净空 |

房间应支持“正常播出”和“节目失控”两个表现状态。失控通过灯光、动画、字幕、音频和少量道具状态变化发生，不把整房替换成另一套传统恐怖资产。

#### 5.1.2 现实玩具工坊视觉基准（2026-09-10 已确认方向）

现实层的默认载体是一张可被看见、可以实际拼装的玩具工坊工作台。它是玩家拥有房间、角色与零件的地方，也是电视梦境投射前后用于确认“这就是我的玩具”的视觉锚点。图一所示的参考工坊进入正式设计，当前 Godot 的 C 参考工坊仍是实现样板；样板中的 A/B/C 切换、测试按钮和性能数据不进入正式玩家界面。

工坊采用中心房间、外围工具、后方工作环境的三层构图：

| 层 | 正式设计要求 |
| --- | --- |
| 中心工作面 | 一块有厚度的实体底座承托当前房间模块；房间的地板、墙、门洞、家具和角色保持可辨认，并展示真实的拼接、卡合和接缝关系 |
| 外围工具与零件 | 绿色切割垫及低对比网格、书本、胶带、笔、零件盘、金属小件等围绕房间自然散落；它们证明房间正在被制作，不改变房间逻辑格、碰撞、门向或战斗路径 |
| 后方工坊环境 | 深色背景墙、蓝色窗、货架、时钟、桌灯或同类工作物件建立“有人在桌前做梦”的尺度；观察镜头旋转时可让最近外墙让开，但不重组中心房间 |

工坊必须让玩家一眼分辨“现实拼装”和“电视梦境”：现实层遵守体积、支撑、接缝、卡槽和物件落点，梦境层才允许房间重组、比例夸张与超现实连接。绿色网格是切割垫的制作纹理，不是战斗网格；外围道具不参与寻路、事件判定或伤害结算。

材质沿用玩具秀的低写实手作语言，并按部件建立稳定分工：底座和墙柱偏哑光塑料，桌椅与书架为涂装木材，沙发、枕头、地毯和床品为布料，灯具、把手和零件为金属，书本与纸张为纸材，花盆等为陶瓷，窗为玻璃，角色保持黏土质感。保留原有孟菲斯配色与贴图，只叠加低对比微表面变化；不使用高对比木纹、强网格或写实 PBR 豪宅来抢走中心房间。

镜头使用与玩具屋一致的等距／正交观察，中心房间占主要视野，外围工作台和后方环境提供尺度参照。默认关闭或弱化景深，确保房间接口、门洞和角色占位清楚；景深只能作为可关闭的表现选项，不能遮挡拼装信息。房间落件、底座卡合、迟到零件回弹和角色跳入是现实层的正式表现证据；动画只移动视觉节点，不改变房间实例和逻辑坐标。

工坊不是第二套玩法，不设置材料加工、制作经营、工坊资源或家具数值。它的正式验收是：玩家能指出自己实际拼了哪间房；关闭电视后仍能在工作台上认出同一房间；从工坊切入电视梦境时，房间的标志性轮廓和主家具仍可被认出；退出或梦醒后，角色和房间回到工作台，不删除或改写玩家资产。

首个正式推广对象是一间可完整展示的示范房及其工坊布景。通过视觉验收后，再按同一构图、材质和拼装契约扩展其他房间；不要先把 C 测试区的所有装饰复制到全图。

#### 5.1.3 Boss 纸盒舞台视觉实现锁

网页原型先用 CSS/SVG 验证构图与信息层级；Godot 工程建立后按同一参数迁移，不重新发明视觉语言。

| 层 | 实现规格 |
| --- | --- |
| 镜头 | `Camera3D` 正交投影；Yaw `45°`，Pitch `35.264°`；固定朝向，不允许常态自由旋转 |
| 房间 | 每格为有厚度的纸盒托盘；顶面保持可读，侧面厚度约格宽 `12%～18%`；门洞贴合菱形边 |
| 比例 | 玩家视觉高度约单格 `1.4×`；Boss `2.5～3×`，允许视觉跨格但逻辑占格不变 |
| 灯光 | 玩家暖橙聚光、Boss 洋红侧逆光、信号锚暖橙点光；环境底色深墨 `#12141D` |
| 材质 | 纸板高粗糙度、黏土中高粗糙度；法线只表现纸纤维/指纹，不叠赛博描边 |
| 后期 | 暗角与 CRT 扫描线放在 `CanvasLayer` / Compositor；不得降低格线、威胁区和门向可读性 |
| HUD | `CanvasLayer` 顶部节目票根高 `64～72px`；右侧手牌栏保持 `300px` 等效宽度；战斗全程单屏 |
| 动效 | 镜头震动、强闪和近景只用于阶段切换/终结，单次约 `0.3～1s`；玩家回合常态保持稳定全局视野 |

### 5.2 音频

- 节目旁白、串台杂音、对讲机/电视机失真（多人尖叫尤其靠听）  
- 战斗反馈短促；Boss「播出」用广播感压迫  

### 5.3 文案语气

短、怪、像主持人念稿；嘲笑**节目组/失控布景**，避免纯羞辱玩家。

## 6. 三阶段多人演出与终幕破坏秀

状态：2026-09-10 已确认设计方向；评分、抽选、胜负与联机实现尚待验证。本节更新旧“半场固定揭晓奸徒”口径，历史多人短稿仅供追溯。核心是演出，欢乐是目的，不采用搜打撤循环。

### 6.1 恰好三个阶段

| 阶段 | 玩家关系与玩法 | 阶段积累 |
| --- | --- | --- |
| 第一阶段：共同玩耍 | 合作探索、搭房、战斗和小玩法，建立共同梦境 | 自建房作为第一阶段投注；积累表现和地块经历 |
| 第二阶段：梦境混乱 | 逐渐加入对抗事件；玩家可能无意或被迫伤害同伴 | 继续信物投入、评分与剧本素材选择 |
| 第三阶段：最终演出 | 对抗与失控升级；末尾 Boss 战以“颁奖仪式／狗腿子颁奖仪式”展开，成为故意把一切搞砸的破坏秀 | 三阶段素材与演出成绩在终幕兑现 |

第三阶段末尾的 Boss 战就是颁奖与破坏秀的高潮，不额外增加第四阶段。颁奖、选角和变身在该节点内如何衔接尚待设计。三个阶段不自动等于三层楼或固定三个 Boss；阶段长度与小 Boss 数量未定。

### 6.2 房间与信物投注

- 开局投入源于局外房间构建：玩家将自己构建的房间作为第一阶段投注，可在该阶段弃权。后续阶段节点也可选择放置信物。
- 投注候选为该玩家走过的地块。自建房进入实际探索经历后，成为影响本局内容的素材；候选池如何跨玩家合并、截取时间如何确定，另行验证。
- 全员弃权时，系统从玩家已踩过的房间中随机挑选，表现类似轮盘赌。有投注也只增加对结果的影响，不能出现唯一投注者必然锁定该结局的规则。
- 抽选权重倾向受伤最厉害的区域，让最狼狈的经历成为节目再次放大的素材。伤害按区域、玩家或事件如何统计，权重上限和防重复刷伤尚未确定；全员弃权是否也使用伤害权重未定。
- 所有房间在局内一次性使用、不重复出现；不表示局外已拥有的房间资产被永久销毁。“不重复”按模板还是实例、以及多人携带同房如何处理，待验证。
- 鼓励第一、第二阶段较早放下自制房：越早拿到自己的房间，越容易获取自己配置的牌组。个人构筑的确定性提高，投入的房间同时给共同剧本增加变化；不承诺直接领取整套牌。
- 自制房是可随时放置的万能房，还是进入卡堆随机获得，尚未确定。

### 6.3 演出评分与选角

“竞价累计”改按马里奥派对式的表现累计与颁奖结算方向设计，不默认使用出价拍卖、支付货币或投注额最高的算法。

信物同时参与评分和剧本生成：越稀有、难度越高的房间加分越多。两项属性如何计分及自建房如何判定难度尚未确定。

评分结构候选为：小玩法、战斗、事件表现 + 信物投入得分 + 结算奖项。具体项目、倍率、奖项公开程度与平分规则未决，暂不自动照搬星星／金币系统。出演排名用来分配终幕反派资格，不直接宣告整局战斗胜利，也不自动给予战斗属性优势。

### 6.4 阶段 Boss 与剧本生成

- 小节点 Boss 的素材来源为玩家初始投入的遗物或房间；结合候选房间规则进行选择，具体触发时点未锁定。
- 系统在三个阶段各挑选一名玩家的信物／房间素材，将其组合为本局最终剧本。具体组合映射、合法性约束和无人投入时的素材替代，待验证；不得因为只有一人投入就保证抽中其指定结局。
- 谁出演与演什么是两个结算结果，共享信物等输入：演出评分决定出演资格，地块经历与投入按概率影响剧本。
- 终幕保留 PvE 可能性，不强制每局由玩家变身；PvE 如何产生、如何处理排名与出演资格尚未确定。
- 设计应允许熟悉剧本后仍享受互动与演出，不以保密胜利规则或查小抄难度作为核心乐趣。

### 6.5 最终破坏秀与梦醒

节目表彰玩家前三阶段的表现，授予制造终幕混乱的出演机会。前面共同放下的房间、收集的物品与积累的事故，成为最终演出的素材；节目为了更热闹的场面而显露邪恶本质。

反派制造大场面，其他玩家仍能反击、拆招、救场或进一步放大混乱。故意搞砸是高潮的演出方向，不等于系统强制无操作的失败；具体胜负、可破坏范围、玩家参与方式待设计。梦终会醒，角色失去活力，重新成为玩具。

Boss 战前不直接死亡是当前生存设计倾向；应允许受伤与事故继续积累。阶段小 Boss 是否也适用例外、倒地代价及最终战败规则均未决。

### 6.6 实现边界

第 3 节记录旧单机原型，不能作为本节三阶段已经实现的证据。现有大地图物理格 Boss 说明见 [大地图 Boss 第一版](./大地图Boss试玩说明.md)。旧“一房压成一格、范围外即时脱战”多人草案不作为当前正式规则；多人回合、同时行动与联机同步需单独设计。

## 8. 分期里程碑与招标包

报价请按包拆开；**默认只采买当前勾选包**。人月为「熟练独立游戏程序+关卡」量级粗估，含联调不含发行市场。

### 包 A — 单人网页「节目感一集」打磨（优先）

**目标**：从「跑团规则模拟」推到「短、怪、记得住的一集」。  

范围：压战斗占比；补 1～2 种短事件（如拼图）；旁白/播出包装；Boss 手感与中段曲线；内容小扩（牌/房）；增加 Lili「事实日志 → 本集回顾 → 记忆碎片」最小闭环；不换引擎，不做运行时生图。

**工期**：约 **1.5～3 人月**  
**验收**：陌生玩家 25～40 分钟打通或明确失败；能复述「放置走位」与「节目感」；回顾与战局一致且 Lili 口吻可辨；AI 不可用时仍能正常结算。

### 包 B — Godot 单机技术样片

**目标**：同规则迁引擎 + 微缩视觉样板房 + 单人整图 Boss 雏形（压缩格 + 脱战跑）。  

范围：核心战斗迁移；1 集教学节目；1～2 个景深展示房；终局地图原型；基础音画管线；角色档案、回顾空间和后台日常的数据骨架。

**工期**：约 **6～12 人月**  
**验收**：样片可录 3 分钟实机预告；脱战破机关分工在单人下可玩通。

### 包 C — 单机「一季」内容扩写

**目标**：多结局/多 Boss/牌怪池/叙事包装达小型商业独立作；在核心玩法稳定后加入自建 OC、微习惯与角色卡导入导出。

**工期**：约 **1.5～3 人年**（可在 B 后并行美术）  
**验收**：3 次以上重玩动机；一季内系统不再大改。

### 包 D — 三阶段多人演出 + 终幕选角与破坏秀

**目标**：按第 6 节验证合作到对抗、房间／信物评分与概率剧本、第三阶段末尾颁奖选角和 Boss 破坏秀；联机行动规则另行设计。

**工期**：在 C 基础上再 **+1～2 人年**  
**验收方向**：多人完整三阶段演出，信物与经历影响剧本、评分参与选角，终幕双方能参与互动；人数、具体数值与联机验收需重新估算。本包旧工期不构成新范围的承诺。

### 包 E — 旁支（可选）

金山打字式联机追逐等 PvP 小模式——**独立报价**，不阻塞 A/B。

### 9.1 甲方已有

- 可玩网页原型与规则数据  
- 美学与非目标清单  
- 设计短稿与本文  

### 9.2 乙方需提交（投标）

1. 理解复述：一句话 +「不是什么」  
2. 所选包：A/B/C/D/E 及报价、人周拆解  
3. 里程碑与风险（尤其：地图×Boss 范围、联机同步）  
4. 过往作品：空间战术 / 邪典或强风格表现 / 联机（若投 D）  
5. 沟通：能否按第 6 节实现服务共同演出的小玩法、信物评分、概率剧本与终幕选角，避免搜打撤和验人主循环

### 9.3 知识产权与协作

- 角色与 channel 品牌归项目方；外包交付源文件与授权范围合同另定  
- 小步提交；关键玩法先可玩再贴皮  
- 多人派对式互动与颁奖按第 6 节执行；不得擅自改成搜打撤、验人局或与共同梦境无关的小游戏集合。

### 9.4 成功标准（产品级）

玩家离开后记得住四件事中的至少三件：

1. 「我是在用陷阱和走位打架，不是站桩」  
2. 「这像一集坏掉的儿童节目」  
3. （若多人）「我们分头行动，后来有人翻脸 / 有人拖 Boss 有人跑机关」  
4. 「Lili / 我的 OC 记得刚才发生过什么，而且说话像同一个人」

## 10. 风险登记

| 风险 | 等级 | 缓解 |
| --- | --- | --- |
| 小玩法与联机范围蔓延 | 高 | 按三阶段演出目标筛选内容，分包验证 |
| 终局 Boss 范围难调 | 高 | 地图与半径同迭代；先单人验证 |
| 网页规则迁 Godot 损耗 | 中 | 数据驱动；战斗系统单测 |
| 仅规则像跑团、无节目感 | 中 | 包 A 强制做包装与节奏 |
| 奸徒做成狼人杀 | 中 | 验收禁止投票主循环 |
| 内容池不足重玩空洞 | 中 | 包 C 专责内容，不提前开 D |
| AI 回顾编造事实或 OOC | 高 | 结构化日志、事实校验、人设校验、模板降级 |
| AI 成本/延迟阻塞一局 | 中 | 异步生成、限长、缓存；AI 服务不可用时照常结算 |
| OC 功能膨胀成独立陪伴 App | 高 | 只生成与节目经历相关内容；以本文硬否决表验收 |
| 角色与记忆隐私 | 高 | 最小采集、显式授权、可导出/删除；首期不接外部生活数据 |

## 12. 结论（给决策者）

channel 已具备 **可玩的规则心脏**；AI OC 将成为它的 **角色记忆与情感层**，而不是另一款并行产品。项目仍缺节目身体、关卡作者力、可信的局后回顾，以及愿景层的整图/多人。

**推荐采购顺序：A → B → C；D 单列评估。**  
用包 A 同时证明「邪典节目一集」和「一个记得这集的角色」成立，再为微缩 3D、自由 OC 与 Haunt 终局付钱。AI OC 的扩展不得先于核心肉鸽体验成立。

## 已实现

- 标题 → 后台测试 → 单人三阶段样片入口，使用 `user://solo_stage_trial_v1.json` 独立存档。
- 第 4、8、12 个进度节点分别触发一次阶段抽片；每阶段只能投入一间已走过的房间或弃权。
- 候选按房间实例记录，房间模板不重复；候选不足两间时延迟抽片并提示继续探索。
- 实际生命损失进入房间经历账本；样片普通房失败后恢复至半血、完成一次房间并继续探索。
- 三次结果保存后组成节目单。第一份房间决定冲撞距离，第二份决定关锚后的奖励，第三份决定扫场或取景规则。
- 单人终幕固定使用 `channel_host` 的 PvE Boss；没有虚拟参赛者、竞价对手或反派排名。
- Boss 入场先亮相三份素材；终幕结束后保存真实胜负结果，播放收束与来源回顾，玩具停止动作。
- 明确的样片存档恢复路径：待揭晓结果只播放已保存结果，终幕与结局恢复后不重新抽片。

## 自动测试与边界

`solo_three_stage_flow_regression.gd` 使用四类测试段落：

1. **状态模拟**：通过奖励结算回调模拟进度节点，分别验证三次投入、三次弃权、阶段结果持久化和候选不足延迟。
2. **真实运行接线**：通过正式 `channel_3d.tscn` 的节目单、Boss 初始化和运行存档路径验证终幕 profile 被传入实际战斗规则；终幕胜负本身由现有 Boss 专项回归覆盖。
3. **真实普通战斗路径**：使用正式战斗入口和战斗引擎的致命受击路径验证样片普通房失败后的恢复与一次性完成；失败结果为确定性注入，目的在于验证结算边界，不是平衡测试。
4. **隔离性**：测试保留正式存档路径、样片投入路径和样片弃权路径。正式存档只读取并记录完整字节指纹，样片运行只写入独立路径；测试结束后正式存档存在性与指纹必须相同。

规则层的八种终幕组合由 `dream_finale_rules_regression.gd` 覆盖；完整样片流程只选一组实际素材走到 Boss，不能据此宣称八种组合都完成了人工验证。缩略图目前使用明确的文字回顾占位，属于已登记的 deferred minor。

## 运行命令

在仓库根目录执行，Godot 路径按本机安装位置替换：

```powershell
$godot = 'D:\godot\Godot_v4.7.1-stable_win64.exe'
$project = (Resolve-Path '.\godot').Path
$tests = @(
  'formal_workshop_regression',
  'solo_stage_flow_regression',
  'dream_room_ledger_regression',
  'dream_draw_rules_regression',
  'dream_stage_panel_regression',
  'dream_finale_profile_regression',
  'dream_finale_rules_regression',
  'solo_three_stage_flow_regression',
  'dream_wake_regression',
  'complete_run_flow_regression',
  'overworld_boss_regression',
  'run_progression_save_regression'
)
foreach ($test in $tests) {
  $process = Start-Process -FilePath $godot -ArgumentList @('--headless', '--path', $project, '--script', "res://tests/$test.gd") -NoNewWindow -PassThru -Wait
  if ($process.ExitCode -ne 0) { throw "$test failed with exit code $($process.ExitCode)" }
}
```

人工运行入口为“标题 → 后台测试 → 单人三阶段样片”。人工检查需要保留每局的存档路径和录屏或截图；不要把测试脚本的确定性注入当作玩家体验记录。

## 人工试玩清单

以下两局是待执行事项，不能用自动回归结果代替：

### 每次投入一局

- [ ] 三个阶段都选择“交给节目”，记录每次候选、提名理由、抽中结果和等待时长。

### 每次弃权一局

- [ ] 三个阶段都选择“本次弃权”，记录节目是否仍然抽出素材以及是否觉得结果可接受。

- [ ] 记录三阶段结束、节目单、Boss 入场和回到现实的理解成本。

每局建议记录：总耗时、每阶段从到达门槛到抽片的等待、首次失败房间、终幕持续时间、回顾信息是否读完、玩家主动复述的因果链。

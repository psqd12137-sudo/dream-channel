# 正式参考工坊验收

这是一间现实玩具层的正式示范房，房间 ID 固定为 `reference_workshop_demo`。它把玩具质感测试中的 C 参考工坊提升为可复用的表现契约，作为后续房间和电视梦境投射的视觉基准。

## 构图契约

- 中央是实体房间底座与主家具轮廓，门洞、逻辑格和角色占位由正式房间系统继续管理。
- 底座外围保留绿色低对比网格切割垫，网格只表达制作台材质，不承担战斗格逻辑。
- 周围至少出现两类制作零件：书本与胶带，零件盘和金属小件作为可识别的补充层。
- 后方保持深色墙、蓝色窗、货架、时钟与桌灯，提供“正在制作中的真实房间”背景。
- 物件按哑光塑料、涂装木材、布料、金属、纸张、陶瓷、玻璃、黏土区分；微表面细节低对比，不能压过房间接口。

## 镜头、灯光与拼装

采用正交等距的桌面观察镜头。中心房间占主要视野，旋转时只让靠近镜头的外墙让位；景深默认关闭或弱化，门洞和角色占位始终清楚。暖色桌灯与蓝窗冷色补光共同照亮制作台。

拼装沿用 `toy_room_assembly`：底座先落下，墙体随后卡合，迟到的零件和角色入场只改变视觉节点。拼装不修改房间逻辑、不增加 `room_prop` 交互槽。所有工坊装饰节点加入 `workshop_decor` 组，便于审查和隔离。

## 工坊与电视梦境的最小验证

样片 API 依次执行：

1. `start_formal_workshop_preview("reference_workshop_demo")` 进入工坊。
2. `enter_formal_tv_dream_preview()` 将同一房间投射到电视梦境，比例可夸张，但主家具轮廓和 room ID 保持不变。
3. `return_formal_workshop_preview()` 恢复现实工坊构图。

入口使用独立样片存档，不改正式续玩存档。C 参考工坊按钮和快捷键继续保留，仍是测试入口；正式契约由 `FormalWorkshopProfile` 与本验收文件共同约束。

## 通过标准

`formal_workshop_regression.gd` 必须确认：中心底座、绿色切割垫、外围零件和后方环境存在；装饰不进入 `room_prop`；梦境投射复用 room ID 与主家具轮廓；房间逻辑、环境、景深和样片存档在返回后恢复。

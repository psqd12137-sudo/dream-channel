# 完整一局流程修复与验收

目标：修复已复现的成长、续玩、未知房和地编问题，以正式一局闭环为后续优先级。
依据：docs/design/织梦频道_channel_dream_策划案与招标书.md 第 3 节；用户已授权直接执行。

- 成长：channel_3d.gd 将相对开局速度成长加入固定基础行动力；下一战验证 5→6。
- 续玩：存储 rng.state 的十进制字符串，加载场景重建后恢复；旧档无此字段时兼容种子回退。验证相同检查点后续奖励相同。
- 未知房：摆放提示与日志去掉真实名称；验证 revealed=false 时不泄露。
- 地编：先选 1/3/5 格再选中文房名；房型从正式目录读取，副本有无从正式内容及显式映射读取；选形状不再清空房间身份。
- 副本：正式战斗读取独立布局，空间节点单独渲染，不从家具生成敌人或逻辑阻挡；无文件回退现有布景。
- 验证：隔离存档下运行跨环节回归、既有存档/Boss/多格/地编测试，记录与策划仍有差距的项目。

后续完整一局验收：主页→预兆→逐房探索/战斗/事件→成长→祭坛→胜败结局→返回主页；中途续玩一致。自动测试允许模拟战斗结果来覆盖状态迁移，但不代替人工正常战斗通关和平衡验收。当前正式 12 房计数保留，策划约 10 房作为后续节奏调整依据。

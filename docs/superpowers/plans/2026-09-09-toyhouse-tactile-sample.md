# 实体玩具质感样板制作计划

> 执行方式：获准后沿用当前任务与既有流程，使用 superpowers:executing-plans 按阶段实施。制作已执行，样板仅放入测试区；正式推广仍等待用户审核。

**目标：** 让同一间孟菲斯玩具屋在静止、旋转和拼装时，都更像真实桌面上的实体玩具。

**架构：** 沿用真实房间生成、镜头、卡通拼装与墙体缩入底座流程。在既有后台测试区增加一个质感对比入口，使用同一场景切换表现配置；外围道具与装饰单独分组，不进入规则、寻路、点击和房间包围盒计算。测试配置经过审核后才能推广至正式版本。

**技术基础：** 当前 Godot 4.7 工程、Forward+、现有材质与环境光、现有景深开关。

**设计依据：** 本轮对话已确认的孟菲斯玩具盒设定，以及小红书案例的拆件工作台、赛车近景、房间俯瞰三个观察画面。借鉴可见的材质、尺度参照与明暗组织，不假定原案例采用了某种渲染算法。

## 1. 范围与视觉方向

- 一间已揭示的 hall 样板房，包含现有角色、家具、墙件和底座；正式未知房间的揭示规则保持原样。
- 奶油色桌面、青绿色盒边，珊瑚粉和柠檬黄作点缀；孟菲斯图案集中在少数面上。
- 优先提升外围桌面、材质区别、接触阴影；轻景深为可单独关闭的第四项。
- 保留已认可的画面外落件、放慢节奏、夸张回弹和墙壁缩入底座，不重写动画曲线。
- 本轮不包含新玩法、音效、镜头特写、拆件预览流程或全地图资产重制。

## 2. 游戏内验收入口

入口：标题 → 后台测试 →「实体玩具质感对比」。

- A「当前画面」：进入测试时保存的原有材质、环境和镜头配置。
- B「质感样板」：开启本轮样板配置。
- A/B 共用房型、布局、角色位置、灯光之外的场景状态及同一个镜头。切换不能重新随机生成房间或改变取景。
- 提供「外围桌面 / 材质层次 / 接触阴影 / 轻景深」四个独立开关，便于判断是哪一项改善或破坏画面。
- 沿用拖拽旋转和滚轮缩放；提供「复位镜头」「重播拼装」。动画播放中切换表现时，从相同初始状态重播，避免半途换配置影响比较。
- 使用隔离存档。退出测试恢复原来的环境、材质和景深设置；不保存实验参数至用户正式设置。

## 3. 分阶段制作

### P0：锁定基线与对比入口

- [x] 保存当前代码版本与固定样板布局，记录初始镜头和视觉设置。
- [x] 建立上述游戏内入口，先让 A/B 都指向当前配置。
- [x] 验证切换、旋转、重播和退出不会改变布局、存档或全局材质。

交付：可在游戏中操作的空白对比框架；此时 A/B 应完全一致。

### P1：桌面与尺度参照

- [x] 在底座外围增加低对比度桌面，让盒边外有可读的留白。
- [x] 增加三类简单道具：两三块积木、一叠贴纸纸张、一个小收纳盒。优先复用模型或简单几何，不引入新资产依赖。
- [x] 道具放在外侧，不遮挡门洞、角色和建造位置，也不截住落件路径。
- [x] 用统一比例表达“房间是玩具、桌面是外部世界”，四个主要旋转方向都检查构图。

验收：一眼能看出盒子摆在桌上；外围物件不抢房间焦点，不让镜头为了容纳装饰而自动拉远。

### P2：材质区别与边缘

- [x] 将样板材质分为涂漆木件、塑料连接件、黏土角色、毛毡软装和纸张五类。
- [x] 调整起始粗糙度范围：涂漆木件 0.35–0.55、塑料 0.25–0.40、黏土 0.75–0.90、毛毡 0.90–1.00、纸张 0.80–0.95。以实机观感为准，非统一覆盖全部模型。
- [x] 塑料和木件保留宽而柔和的高光，避免整间房变成镜面或湿漉漉的外观。
- [x] 对近景中最生硬的底座、柱帽、桌面边缘优先试做小倒角；需要修改轮廓时使用几何，不靠调粗糙度冒充倒角。
- [x] 保留源贴图与资源，通过独立的测试材质实例调整，确保退出时可完整恢复。

验收：同一光照下能区分硬件、角色和软装；孟菲斯色块与纹样保持清楚，不出现明显噪点和重复纹理。

### P3：柔光与接触阴影

- [x] 复用现有主光、补光、天空反射及 SSAO，先整理主次关系，再决定是否需要额外反射配置。
- [x] 重点检查墙脚、椅脚、家具底部、模块接缝；阴影贴住接触点并柔和扩散，避免整圈黑边。
- [x] 保持房间主体比外围环境更易读，背光面仍能看清颜色和门洞。
- [x] 重播拼装与墙体收缩，检查运动时阴影不会明显闪跳或在空中留下黑斑。

验收：零件落稳后有重量感；小尺寸窗口和背光角度下角色仍清楚。截图不能代替运动过程验收。

### P4：轻景深可行性检查

- [x] 先复用现有景深开关。当前实现是屏幕带状模糊，扩大清晰区域并降低强度，检查四个旋转方向及远近缩放。
- [x] 角色、门洞、当前房间的可操作区域必须清晰；景深只用于弱化外围环境，HUD 不受影响。
- [x] 如果带状模糊无法满足要求，样板默认关闭景深，并明确记录原因。按深度控制焦点的改造列为后续独立提案，不在本轮悄悄扩展范围。

验收：景深开关只有在不损害可读性时才纳入推荐 B 配置。

### P5：实机审核与推广边界

- [x] 同一镜头下逐项切换，并比较完整 A/B 配置。
- [x] 在四个主要朝向、最近/默认/最远缩放检查静止画面。
- [x] 检查拼装、角色入场、墙体缩入底座、反复重播和退出再进入。
- [x] 同一设备、分辨率与场景，预热后对 A/B 各记录至少 30 秒帧时间，目标是 B 平均帧时间增长不超过 15%，且不新增明显卡顿；不达标先降低装饰或效果成本。
- [x] 复查正式建造、未知揭示、存档及战斗光照恢复，确保测试设置不外泄。
- [x] 提交游戏内可体验的样板与效果清单，由用户审核。正式推广另行获准后，先接入这间房，再覆盖其他房型。

## 5. 制作量与交付

粗估：对比入口与隔离 0.5 天；桌面与材质 1–1.5 天；灯光、景深检查与实机验收 0.5–1 天，合计约 2–3 个工作日。按复用现有资产估算；如需定制家具或深度景深，另行估算。

最终交付为：一个真实游戏内的对比入口、一套推荐的样板表现、四项可独立检查的效果及验收记录。本轮到用户审核样板为止，不默认推广全图。

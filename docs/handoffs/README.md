# Agent 交接区

状态：客户端事实

本目录保存面向下一位开发 Agent 的提交交接记录。功能提交必须同时新增或更新一份交接文档，避免实现约束只存在于聊天上下文中。

## 提交规则

1. 文件名使用 `YYYY-MM-DD-主题.md`；同一天同主题继续开发时更新原文件，不重复制造空壳记录。
2. 至少记录改动范围、关键文件与接口、必须保持的不变量、实际执行的验证、遗留问题和建议下一步。
3. 只写仓库中已经落地的事实。设想和未确认方向继续登记到 `docs/open-questions.md`。
4. 截图等忽略产物只记录生成路径和生成命令，不把本机绝对路径写成项目依赖。
5. 本地 MCP、编辑器缓存、临时实验目录和密钥不得进入提交。

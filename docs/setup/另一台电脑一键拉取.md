# 另一台电脑 · 一键拉取《织梦频道 channel dream》

把下面整段复制到新电脑的终端执行即可（需已安装 Git、Python3）。日常可简称 **channel**。


---

## macOS / Linux

```bash
# 1) 拉取项目（私有库：按提示登录 GitHub）
git clone https://github.com/psqd12137-sudo/dream-channel.git
cd dream-channel

# 2) 启动竖切片
cd cabin-slice
python3 -m http.server 8787
```

浏览器打开：

```text
http://127.0.0.1:8787/
```

硬刷新一次（Mac：`Cmd+Shift+R`），点「打开电视机」开始。

## 私有仓库登录（只做一次）

若 `git clone` 提示没权限：

1. 打开 https://github.com/login 用账号 `psqd12137-sudo` 登录  
2. 或安装 GitHub CLI 后执行：`gh auth login`  
3. 再重新 `git clone`

推荐用 HTTPS + 浏览器登录；也可在 GitHub → Settings → Developer settings → Personal access tokens 建 token，clone 时密码处粘贴 token。

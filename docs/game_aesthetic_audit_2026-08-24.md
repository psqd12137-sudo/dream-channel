# 游戏内审美审查与整改清单（2026-08-24）

## 1. 目标与判断基线

本清单以正式 Godot 对局为第一优先级，地编工具和后台测试场景只在其视觉问题会流入正式游戏时处理。目标不是把素材继续堆进场景，而是让大地图、战斗房、UI 和镜头共同服务于同一个视觉概念：

- 80 年代电视节目包装；
- 绿色手工垫板上的纸盒微缩片场；
- KayKit 木地板作为房间统一尺度；
- 房间中的家具布局在大地图与战斗房之间保持身份连续；
- 玩法信息用图形、色彩和动画表达，避免调试式悬浮文字。

审查证据来自 1280×800 实际 Vulkan 截图，而不是只看节点树：

- `godot/artifacts/completion_00_home.png`
- `godot/artifacts/camera_house_default.png`

## 2. 本轮已经修复

### 2.1 战斗地板规格统一

- 战斗房不再使用白色厚方块作为可见地板。
- 正式复用大地图的 `floor_wood_large.gltf.glb`，根据模型真实长宽比在每个战斗格内铺两块木板，不再把长方形模型强行等比拉成桌面状方块。
- 房间 footprint 内使用连续木板；footprint 外的逻辑格改成绿色切割垫板、细网格和少量胶带，明确属于片场后台而不是另一层房间。
- 纸板墙严格沿 1/3/5 格 footprint 外轮廓生成，内部格线不建墙；门洞取入口边，转角柱只出现在真实轮廓转折处。
- 每格仍保留不可见逻辑 `Surface`，不改变拾取、移动和高度判定。

### 2.2 清除 3D 调试文字

- 删除战斗格上的 `H1/H2`。
- 删除房间上方“某某房 · 当前房间”。
- 删除怪物头顶“怪/?”。
- 正式大地图 composer 已明确设置 `show_room_ids = false`、`show_summary_title = false`。

### 2.3 战斗提示图形化

- 敌方意图改为角色上方的小型彩色徽章。
- 移动路径由整格蓝色面板和“走1/走2”改为小型编号圆点。
- 攻击范围由整格文字面板改为红色警告圆点与四角标记。
- 普通移动范围不再常驻铺满青色角点，只在悬浮目标时显示；选中放置牌时仍显示完整可放区域。
- 家具顶部的逻辑站立面保留但默认隐藏。

### 2.4 战斗 UI 层级整理

- 行动力票据从右下角移到玩家与敌人状态栏之间。
- 回合结束按钮移到弃牌堆左侧，不再覆盖弃牌堆。
- 自动取景减少空背景安全边距，房间模型约放大 11%，旋转四角仍通过回归测试。

### 2.5 PCG 构图不再阵列式撒道具

- 房间资产引入 `anchor / support / clutter / wall_bound` 语义层、同模型数量上限和主题组合关系。
- 候选位置会惩罚共线阵列、过度分散和单格拥挤，并奖励主家具附近的语义搭配。
- 厨房补入中型橱柜，避免内容池不足时只能重复摆凳；固定 Seed 2–25 已通过重复度、门洞遮挡和构图回归。
- 手调 override 与程序房统一经过暖纸色、低金属、高粗糙度的运行时材质归一，不修改第三方源文件。

### 2.6 高低差改为可读的片场结构

- 只有桌、床、沙发等宽面家具能成为 H1 的房间主题主件；灯、植物、窄书架不再整格阻挡或充当平台。
- 其余 H1 合并成连续深木舞台，并用薄支脚、斜撑和胶带表现可站立高度，避免同一张桌子复制成阵列。
- H2 只使用楼梯和木结构变体，不再把冰箱、壁炉或书架粗暴拉高。
- 可站立逻辑面与阻挡体保留但默认不可见；阻挡格不再显示绿色透明立方体或悬浮 `×`。

### 2.7 大地图可读性清理

- 取景只计算已摆房间；普通未来插槽不再把开局房间缩成邮票，只有当前选中的多格预览参与扩框。
- 金色悬浮 `+` 改成低矮建造插座与电视信号条。
- 未揭示房覆盖改成带青/黄胶带的彩色纸盖，不再像缺失材质的灰块。
- 玩家/怪物脚下棋子底座改成更薄、更透明的纸片圈。

## 3. 本轮后的观察项

### P0：已完成并纳入回归基线

#### A. 非手调房间构图

完成：已加入主次语义、同模型上限、门口禁区、共线/分散/拥挤惩罚与语义搭配评分；固定 Seed 批量回归防止重新退化为阵列。

#### B. 大地图与战斗 footprint

完成：1/3/5 格 footprint 直接驱动木地板、纸板墙、门洞、转角和后台垫板；玩法仍使用原战斗网格，不改变 `HOUSE_CELL` 或战斗结算。

#### C. 高低差语义

完成：以 `battle_height_class`、`battle_blocker` 和 terrain profile 做白名单；H1 主件、连续舞台与 H2 楼梯/木结构分开表现，逻辑站立面保持隐藏。

#### D. 跨资产包材质一致性

完成：正式房壳统一纸板，家具运行时复制材质并压低金属度/高光、提高粗糙度、混入暖纸调色；原始模型与贴图保持不动。

### P1：主要可见项已完成

#### E. 战斗 UI 与 3D 色彩竞争

- 已使用无边框全幅战场、底部手牌弧线、两侧小型牌堆和居中的行动力票据分离信息层级。
- 静止手牌只露上半，只有悬浮牌升起放大；房间在非查看卡牌时仍是主要视觉焦点。
- 角色状态、意图和行动力使用图形与高对比主数字，正式画面不再依赖战斗导播或大段说明文字。

#### F. 大地图早期构图过小

- 已改为根据已摆房间取景；仅当前扩建预览会参与临时扩框。
- frontier 已改为纸片建造插座和电视信号条，不再显示悬浮 `+`。

#### G. 未揭示房间看起来像缺材质

- 已替换为带青/黄胶带的彩色纸盖；揭示动画仍沿用既有片场展开流程。

#### H. 角色与地面接触感不足

- 脚下底座已改成薄而低透明的纸片圈；模型与家具继续使用统一投影和接触阴影。

#### I. 战斗镜头缺少事件构图

- 当前保留攻击/受击动作、落入场和房间构建动画；镜头始终优先保证完整战术信息。
- 后续若加入攻击推近或手持震动，必须做成可关闭的低强度包装选项，不能影响地块点击与晕动敏感玩家。

### P2：包装与后台场景

#### J. 首页控制区拥挤

- 视频主页和 80 年代标题方向正确，但下方按钮、种子输入、分辨率与退出同屏竞争。
- 正式首页只保留“开始/继续/新手教学”；分辨率、窗口、移轴和退出收进设置面板。
- 后台测试入口只在开发构建显示。

#### K. 后台测试场景仍是占位美术

- 横版测试：几何平台与空背景。
- 九宫格测试：纯色方块，没有纸片/电视节目语汇。
- 搜索房测试：盒子式原型，没有正式房间资产。

这些不应阻塞正式游戏，但如果后台测试会出现在公开试玩包里，需要加统一的“开发中/片场排练”包装，避免玩家误认为是正式完成度。

#### L. 字体层级不够稳定

- 展示字体适合标题和按钮，不应覆盖长说明。
- 正文字体在 1280×720 下不得小于 11px；灰字与深背景对比至少维持 4.5:1。
- 中文按钮宽度按最差字串预留，避免多语言替换后拥挤。

## 4. 每轮美术回归必须截图的状态

1. 首页：1280×720 与 1920×1080。
2. 大地图：只有 1 个房、已有 3 个房、已有 5 个房。
3. 房间摆放：长条 3 格旋转前后、L3 旋转前后、T5 旋转前后。
4. 普通战斗：自动生成房、手调 override 房各一张。
5. 精英战斗：默认镜头、旋转 90°、最大/最小缩放。
6. 卡牌：静止、悬浮、拖动箭头、可放/不可放目标。
7. 敌方意图：移动、攻击、多段攻击、未揭示。
8. 高低差：玩家站在 H1/H2 资产上，不能出现悬空或穿模。
9. 建造动画：开头、中段、完成后三帧。

## 5. 可量化验收线

- 正式 3D 场景中悬浮调试文字数量：0。
- 战斗默认镜头中房间占可用战场宽度：60%–82%；高度：55%–78%。
- UI、牌堆、按钮之间的像素重叠：0。
- 门前一个玩法格范围内的不可穿越装饰物：0。
- 相邻重复小道具：0；同模型同房默认不超过 2 个。
- 每房至少 1 个视觉焦点、1 条连续主通道、1 组语义家具组合。
- 手调 override 房进入战斗后，焦点家具、门方向和 footprint 三项全部可辨认。
- 旋转任意角度后，房间外轮廓、玩家、敌人和入口均在画面内。
- 1280×720 下所有正式玩法文字清晰可读，不依赖截图放大。

## 6. 推荐执行顺序

1. footprint 驱动战斗外壳，并把外围逻辑格改成绿色片场后台。
2. 给 PCG 资产增加语义层与构图评分，消除阵列式重复。
3. 增加高低差资产白名单和精确站立面数据。
4. 建立材质归一层和房间主题调色板。
5. 优化大地图早期取景、未知房遮罩和 frontier 图形。
6. 最后统一角色脚圈、事件镜头、首页设置层级和后台测试包装。

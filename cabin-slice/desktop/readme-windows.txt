织梦频道 · Cabin Slice — Windows 版使用说明
============================================

一、怎么开始玩
  1. 双击 CabinSlice_织梦频道.exe。
  2. 会自动打开你的默认浏览器，进入游戏（地址是 http://127.0.0.1:17887/）。
  3. 玩完后，把弹出的黑色「控制台窗口」关掉，游戏服务就停止了。

二、常见问题
  · 双击没反应？
    稍等 1-2 秒，浏览器会自动弹出。如果浏览器没开，
    手动打开浏览器，地址栏输入 http://127.0.0.1:17887/ 即可。

  · 弹出黑窗口提示「无法监听」？
    说明 17887 端口被占用（比如你已经开了一个本程序）。
    关掉之前的程序再试，或者直接访问上面地址。

  · 存档在哪？
    游戏存档保存在浏览器里（localStorage），换电脑/浏览器不会带过去。
    请用同一台电脑、同一个浏览器玩，进度才不会丢。

  · 想彻底卸载？
    直接删除整个文件夹即可，不写注册表、不留后台进程。

三、Windows 常见提示
  · SmartScreen「已保护你的电脑」？
    本程序没有数字签名（个人分发常见）。点「更多信息」→「仍要运行」即可。
  · 需要 64 位 Windows（Win10/Win11）。本地只监听 127.0.0.1，不需要防火墙放行。

四、给开发者的打包方法
  在 macOS 上重新打包：
    cd cabin-slice && ./desktop/build.sh
  需要 Go 1.21+（macOS 上可直接交叉编译出 Windows x64 exe）。

—— 单机离线可玩，不需要联网，不需要安装任何东西。

# 出牌规则（Run Scheme v3）

## 双主线

1. 节点损失最小化 → 获得加牌机会 → 自己判断是否卡手  
2. 指纹猜 Boss → 开战面板看含压力加成的实战数值  

## 成长

- **开局**：行前预兆二选一
- **牌库为主**：战斗胜利 2 选 1；道具房也可能给牌
- **遗物节点**：池 8 枚；中点（已结算 ≥4）下一非战斗房保底一枚
- **数值**：静室每次两选，速度出现率更低

## 战斗

- 抽 4；体力 = S·d3（0/1/2），「预兆·信号」再 +1
- 意图可见；**默认不能免费留牌**（尖塔向）
- 留牌途径：技巧「预案」（本场每回合可留 1）/「夹带」（本回合可留 1）/ 带「保留」关键字的牌
- **无出牌次数上限**
- 高位打低位伤害 +1；掩体 / 高差可抵挡敌人攻击
- 敌人带「grab」词条时，命中优先偷手牌药物；没药会扯走一张杂物牌
- 敌人技能词条（见 `pressure.json`）：突进贴近 / 突脸惊吓 / 攀爬 / 抄近路 / 避陷阱 / 破防 / 穷追 / 砸地AoE / 激光线
- 埋伏揭开时会免费扑出一步；难度档 3 起敌伤 +1
- **战斗失败 = 本局结束**（进结局页，点「再看一集」重开）；不再逃出节点继续
- **意图看格子**：红格+数字=会受伤；`2×2` = 两段共 4；`→` 后是格挡后实伤；蓝虚线=它下一步；走开红格即可躲
- **段数**：默认单段；只有「连击」词条的怪多段（阁楼 / 地窖 / Boss）
- **行动力**：你和怪用同一套词——你的行动力来自速度骰，怪的行动力花在追你身上就没得打你
- 格挡是池子：技巧/药物**点一下即生效，不用放置**；留在手里不会自动挡伤
- **空间连击**：盐道 / 闪瞎 / 夹击 / 纸影 / 追击踩踏 / 高台砸击 / 隧道——靠布置与引怪，不靠力量层
- **传送格**：踏入即到对端；**推撞**可主动把怪推进陷阱

## 奖励

- 战斗胜利：奖励池摸 2 选 1，收下 / 放弃
- 非战斗房：预兆 / 道具卡 / 数值三类，悬停卡片看详情
- 已摇出的奖励会写进存档——刷新页面不会换结果

## 预兆（战斗外拾取，不可被偷）

- 信号：每回合体力 +1
- 盐环：你造成的伤害 +1
- 镜头：每场战斗首次打出 0 费牌时抽 1
- 回声：生命上限 +1 并回满差额
- 纸影：每场战斗开局手牌 +1 消耗傀儡
- 火漆：每场战斗首次砸击 +2
- 胶靴：攀爬不额外耗体
- 铃铛：埋伏房开场揭开埋伏

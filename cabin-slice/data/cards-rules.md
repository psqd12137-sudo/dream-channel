# 出牌规则（Run Scheme v2）

## 双主线

1. 节点损失最小化 → 获得加牌机会 → 自己判断是否卡手  
2. 指纹猜 Boss → 开战面板看含压力加成的实战数值  

## 战斗

- 抽 4；体力 = S·d3（0/1/2），「预兆·信号」再 +1
- 意图可见；**默认不能免费留牌**（尖塔向）
- 留牌途径：技巧「预案」（本场每回合可留 1）/「夹带」（本回合可留 1）/ 带「保留」关键字的牌
- **无出牌次数上限**
- 高位打低位伤害 +1；掩体 / 高差可抵挡敌人攻击
- 敌人带「grab」词条时，命中你会偷牌；**只偷带「可被偷」的药物**，没药就偷不走
- 战斗失败同理：只丢药物，不丢技巧和放置牌

## 卡牌一览

| 牌 | 费用 | 类型 | 效果 |
| --- | --- | --- | --- |
| 地刺 | 1 | 放置 | 踩上 / 砸中 2 伤 |
| 盐圈 | 1 | 放置 | 敌人进入多耗 1 体力；你站上面受击格挡 +2 |
| 闪光雷 | 2 | 放置 | 踩上 / 砸中 3 伤，并闪瞎（丢失对你的最后目击） |
| 坠物 | 2 | 放置 | 踩上 / 砸中 4 伤 |
| 屏息 | 0 | 技巧 | 下一件放置费用 -1 |
| 预案 | 1 | 技巧 | 本场每回合结束可留 1 张牌 |
| 夹带 | 0 | 技巧 | 本回合结束可留 1 张牌 |
| 护身符 | 1 | 技巧 | 保留；+2 格挡 |
| 补剂 | 0 | 药物 | 体力 +2；可被偷 |
| 肾上腺素 | 1 | 药物 | 体力 +3，自伤 1；可被偷 |

## 奖励

- 战斗胜利：奖励池摸 2 选 1，收下 / 放弃
- 非战斗房：预兆 / 道具卡 / 数值三类，悬停卡片看详情
- 已摇出的奖励会写进存档——刷新页面不会换结果

## 预兆（战斗外拾取，不可被偷）

- 信号：每回合体力 +1
- 盐环：你造成的伤害 +1
- 镜头：每场战斗首次打出 0 费牌时抽 1
- 回声：生命上限 +1 并回满差额

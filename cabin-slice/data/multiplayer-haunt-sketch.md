# channel · 多人山屋设想（设计短稿）

> 非正式规格，只锁定方向。网页单人切片仍是主交付；本文记录多人/终局 Boss 幻想。

正式名：**《织梦频道 channel dream》**（简称 channel）  
气质：怀旧邪典荒诞（*Superjail* 壳）+ Haunt 式考验；**不是**马里奥派对，**不是**狼人杀。

---

## 1. 一集怎么演（恐怖片流程）

```text
大厅集结 → 分头探索 → 单人事件/战斗 → 出事/尖叫 → 合流共担
         →（预兆压满）半场奸徒揭晓 → 不对称后半
         → 终局：整张大地图 Boss
```

- 玩家可**群体进入**同一频道房间（山屋）。
- 按恐怖片惯例**分头行动**：各去各房遇事件；一人出事，人往一处凑。
- 强者快速清完自己的房后，可在**已探明区（大厅）实时 WASD 闲逛**，或进未探区、或加入别人正在探索的房（合战/合探）。
- 设计目标：看见队友最窘迫的样子；听见隔壁尖叫再推门一起面对（致命公司式听觉张力，节目串台包装）。

**时间模型（建议）**

- 大厅 / 过道 / 脱战区：**实时移动**
- 进战房间内：可仍用现有**回合制放置 × 走位**（中途加入从门口格进场）
- 先验证「闲逛 → 听尖叫 → 推门」是否爽，再上真联机

---

## 2. 半场奸徒（山屋惊魂精髓 ≠ 狼人杀）

| 要 | 不要 |
| --- | --- |
| 前半**真合作**探屋、攒预兆 | 开局隐身份、大厅嘴炮投票 |
| 某一刻**规则换页**，有人目标翻面 | 「每晚刀人」抽象权 |
| 奸徒用**空间**害人：假尖叫、锁门、搅局合战、推播出进度 | 验人、放逐、纯社牛局 |

一句话：**不是验身份，是半场改剧本。**  
翻盘前一起清过房、一起听过惨叫——背叛才疼。

金山打字「警察抓小偷」联机：可作**以后 PvP 旁支**，不进山屋主线核心。

## 3. 终局 Boss：整图压缩 + BG3 式战斗检测

Boss 战不锁在单一小战场，而在**整张山屋大地图**：

- **每个房间压缩为一格**（或一节点）；格子上仍按既有对战规则结算（放置、走位、韧性、视线等可按尺度改编）。
- Boss 带**战斗检测范围**（类似博德之门 3）：
  - **范围内**：进入/维持战斗节奏（回合或强制交战）
  - **范围外**：玩家可**即时制**移动——找道具、开门机关、藏匿、绕行
- 由此回到 Haunt 名场面：**一群人拖住 Boss，一人飞毛腿破机关**（或护送、熄锚、关播出）。

### 地图与范围（高要求）

| 若范围… | 后果 |
| --- | --- |
| 过小 | 玩家轻易脱战 → 机关无风险秒开，拖怪无意义 |
| 过大 | 无人能抗、无处藏，飞毛腿也跑不出去 |
| 合适 | 抗住有代价，跑开有路线，藏匿靠结构 |

因此 **视野 / 遮挡 / 噪音** 在终局格外重要：

- 谁在 Boss「感知」里（视锥、听力、墙后偷听）
- 藏起来是否真的脱离检测（掩体、关灯、盐圈/节目静音道具）
- 队友在另一格开门时，Boss 是否被声音吸引转火

地图设计要同时服务三件事：**拖怪点、跑酷线、藏匿点**——不是只铺战斗房间。

## 5. 硬约束备忘

1. 身份：邪典儿童节目，克制小玩法密度  
2. 奸徒：半场翻盘，不是狼人杀  
3. 多人爽点：分头、尖叫、合流、看见窘迫  
4. 终局：整图一格一房 + 脱战即时 + 视野决定能不能玩 Haunt 分工  
5. 范围数值与地图结构必须一起调，不能只调 Boss 半径

# Run Scheme v3 · 放置与移动

## 设计锚点

- 烧牌是战略资源，不进常规奖励
- 推演数据后台化，不给玩家看细账
- 战斗差异点：放置物品 + 移动拉扯敌人体力（反站桩）

## 地形

- `walls`：不可通行，阻挡视线
- `heights`：0–2；向上攀爬额外耗体 = 高差
- 视线：墙遮挡；中间脊（高度 > 双方）遮挡；邻接始终可见
- 无视线：敌方显示 `?`，AI 搜索 `lastSeen`
- 重获视线：突脸
- 高打低：砸物 +1；敌高打你也 +1；你在更高处挨打时略吃地形掩护

## 韧性与机制（压力）

- 共用：逼移动 / 陷阱 / 盐圈削韧；砸击少量削韧
- 破韧奖励分型：处决 / 装甲 / 踉跄 / 破甲 / 布线（见 `pressure.json`）
- 机制词条：`lunge` 距 2 突进 · `faceShock` 重获视线惊吓 · `grab` 命中偷牌 · `relentless` 目击时攻击更便宜
- 已移除：耗体兑换玩家体力（过肥）
- 追击途中踩陷阱仍 +1 伤；无伤本身就是奖

## 节奏

- 战斗序号映射难度档：`1→2→4→3→1→5`（`pressure.combatCurve`）

## 敌人体力与杀意

- 基础体力 3（Boss 4），档位可再加
- AI：击杀欲 > 生存；有视线追击，无视线搜索
- 放置：有视线才可砸敌人脚下

## 物品

见 `cards.json`：`type: place | medicine | skill`

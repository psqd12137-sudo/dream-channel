# Run Scheme v3 · 放置与移动

## 设计锚点

- 烧牌是战略资源，不进常规奖励
- 推演数据后台化，不给玩家看细账
- 战斗差异点：放置物品 + 移动拉扯敌人体力（反站桩）
- **成长主轴：牌库**；遗物做节点跳变；数值只做小步补间

## 成长节奏

1. **开局**：行前预兆二选一（从 8 枚遗物池抽 2）
2. **前段**：战斗掉牌为主
3. **中点**：已结算 ≥4 房后，下一间非战斗房保底遗物（每局一次）
4. **后段**：难度档 4/5 尖峰用牌库 + 遗物兑现
5. 静室数值：每次只出 2 项，速度权重更低（防速度滑坡）

## 地形

- `walls`：不可通行，阻挡视线
- `heights`：0–2；向上攀爬额外耗体 = 高差（遗物「胶靴」免攀爬费）
- `portals`：成对传送格；任何单位踏入一端即到对端；落点陷阱可打出「隧道连击」
- 视线：墙遮挡；中间脊（高度 > 双方）遮挡；邻接始终可见
- 无视线：敌方显示 `?`，AI 搜索 `lastSeen`
- 重获视线：突脸
- 高打低：砸物 +1；敌高打你也 +1；你在更高处挨打时略吃地形掩护

## 分房出生（主题埋伏）

- 每间房 `arena.player / enemy / walls / heights` 各自配置，禁止一律左你右怪
- **墙不得整列/整行把玩家与敌人切开**（窄廊尤其容易）；留缝挡视线、留通道能绕
- 开战时若仍无通路，运行时会自动拆掉挡路墙（防死局兜底）
- `ambush: true`：开场无视线时敌人蹲在出生点不搜索，直到建立视线（「铃铛」遗物可揭开）
- `spawnNote`：进战旁白，说明主题（冰箱顶、货架高处、画框后等）
- 开阔房（如客厅、后院）可对峙开场，形成节奏对比
- 已配置传送的房：西厢、长廊、地窖

## 空间连击（布置 × 引怪，不靠力量层）

| 连击名 | 条件 | 效果 |
| --- | --- | --- |
| 追击踩踏 | 本敌回合已移动 ≥1 再踩伤陷阱 | 陷阱伤 +1 |
| 高台砸击 | 你比敌高时砸击 | 砸击 +1 |
| 盐道连击 | 同敌回合先踩盐再踩伤陷阱 | 伤 +1，再削韧 1 |
| 闪瞎连击 | 本场已 blind，下一次砸击 | 砸击 +2 |
| 夹击连击 | 砸击时敌邻格有刺/盐 | 伤 +1，削韧 1 |
| 纸影连击 | 追傀儡途中踩伤陷阱 | 伤 +1 |
| 隧道连击 | 传送后落在伤陷阱上 | 喊名（伤已由陷阱结算） |

## 纸影傀儡（遗物）

- 「预兆·纸影」：每场战斗开局手牌加入 1 张消耗型「纸影傀儡」
- 放置同地刺（邻格）；场上嘲讽；**挨 1 下才消散**（无回合上限）；场上限 1
- 消耗/临时牌：打出不进弃牌；未打出回合结束或战斗结束清除

## 韧性与机制（压力）

- 共用：**走位引怪踩陷阱 / 盐圈** 削韧；砸击少量削韧（纯追击走路不再削韧）
- 破韧奖励分型：处决 / 装甲 / 踉跄 / 破甲 / 布线（见 `pressure.json`）
- 机制词条（敌人技能）：
  - `lunge` 距 2 真突进：先贴脸再打
  - `faceShock` 重获视线 / 你主动暴露时惊吓
  - `grab` 命中优先偷手牌药物；无药则扯走杂物
  - `relentless` 目击时攻击更便宜
  - `vault` 优先攀高台再打（吃高打低）
  - `cornerCut` 见面免费抄近一步
  - `trapAware` 寻路避开刺/盐圈
  - `guardBreak` 多耗 1 体力打出破防，无视格挡与掩体
  - `slam` 须**邻接**砸地：朝向你的 **2×2** AoE（红格）；距 2 站桩不再能砸
  - `beam` 同行/列距 2–3：**1×3** 激光线（红格）
  - `flurry` 一回合多段攻击（红字写成 `伤害×段数`）；**Boss 不带此词条**
- 埋伏揭开当回合有一次免费扑出（弹簧）
- 已移除：耗体兑换玩家体力（过肥）
- 追击途中踩陷阱仍 +1 伤；无伤本身就是奖

## Boss 仪式（祭坛）

双轨通关：**熄灭全部信号锚** 或 **打空血条**。播出进度满则失败。

- 祭坛场上 4 枚信号锚（耐久 2）；熄灭方式：站上花 2 行动力「拆信号」/ 放置牌砸锚 / **引 Boss 砸地或蓄力覆盖锚点**
- 播出进度：每敌回合推进；有视线额外 +1；熄灭锚点 / 破韧可减速
- 蓄力大招：先蓄一回合（虚线红格预告），下回合必落；可砸灭锚点
- 阶段：熄灭 2→换台（蓄力变宽）；熄灭 3→终幕（时钟加速）
- 公开节目指令：特写（须先移动再打）/ 点亮舞台（追最近亮锚）/ 静音 / 加播

## 意图预警（格子即信息）

玩家不靠长句心算，看战场格子：

| 视觉 | 含义 |
| --- | --- |
| 红底 + 数字 | 伤害区：回合结束站在这里会挨打 |
| 红底 `2×2` | 多段：每段 2 伤、共 2 段（合计 4） |
| 红底 `2×2→2` | 箭头后是扣掉格挡/掩护的实伤 |
| 蓝虚线框 | 移动区：它下一步可能走到这（不直接伤你） |
| 短标签（突进 2 / 逼近挥击 2 / 追击 / 撕影） | 只点题，细节悬停 banner |

- 意图与结算同源：攻击只打 hurt 区内的你；走开即落空
- **红字包含「走一步再打」**：怪能移动后够到你时，红区提前标出（标签带「逼近」），不会出现「显示追击却挨刀」
- **段数锁定**：敌回合开始时按预告锁定刀数，实际不会超出红字
- 同帧只显示一套主威胁（能打的技能优先于移动脚印）
- 追傀儡时蓝线/撕影指向傀儡格

## 多段攻击（尖塔式明示）

- 默认所有怪 **单段**；只有带 `flurry`「连击」词条的怪一回合打多段（阁楼 / 地窖）
- Boss 多段改由**蓄力大招**承担（红格虚线预告）
- 段数受行动力限制：首段耗 `attackCost`，追加段各耗 1 次攻击费
- 格挡是**池子**：掩体/高差每段都吃，卡牌格挡按实际抵消量扣减，不会一碰就清零
- 不做《山屋惊魂》式的力量拼点：本作对抗靠布置与走位，不再叠第二套骰子对拼系统

## 节奏

- 战斗序号映射难度档：`1→2→4→3→1→5`（`pressure.combatCurve`）
- 难度档 3 起伤害 +1（中段不再全被盐圈吃掉）
- **任意战斗失败即终局**（清存档 → 结局页 →「再看一集」）；普通战不再「逃出节点」续玩

## 敌人体力与杀意

- 基础体力 3（Boss 4），档位可再加
- AI：击杀欲 > 生存；有视线追击，无视线搜索；**场上有傀儡时优先追打傀儡**
- 放置：有视线才可砸敌人脚下

## 物品

见 `cards.json`：`type: place | medicine | skill`；另有消耗临时牌 `decoy`、位移牌 `shove` / `snare`

# 织梦频道 channel dream · 山屋切片（Run Scheme v3）

正式名 **《织梦频道 channel dream》**（简称 **channel**）。本目录是其中一集竖切片 demo。

**美学**：怀旧邪典荒诞——儿童节目外壳、失控的超现实内核（气质接近 *Superjail*）；山屋惊魂式考验，不是派对合集。

与杀戮尖塔的核心差异：**出牌 = 往场地放物品；移动迫使敌人把行动力花在追击上**，而不是站桩结算。

气质上别人常联想到《蓝途王子》的「大宅开路」——我们保留空间魅力，但主循环仍是遭遇与放置走位；静室不该只剩平铺直叙的弹窗。


## 运行

```bash
cd cabin-slice
python3 -m http.server 8787
```

浏览器打开：http://127.0.0.1:8787/

- 存档键 `cabin-run-v3`（进行中的一局；胜负会清除）
- **实验记录** `cabin-lab-v1`：每场战斗的胜负、回合、输出/受伤、破韧、连击、牌库与遗物快照会保留，标题页可导出 JSON（最多 40 场）
- 自测脚本：`scripts/boss_selftest.py`、`scripts/full_selftest.py`（需 Playwright）

新开一局请点「打开电视机」。测 Boss 用「跳到 Boss（测强度）」。标题「测 WASD 手感 / 测 QTE」为临时沙盒；第二视角最终走 3D 微缩景深。行程里泥靴间已挂 `eventType: qte`。

## 一局怎么玩

1. **开局**：行前预兆二选一（8 枚遗物池）；起手生命 **6**，含 **护身符** 即时格挡
2. **探索**：6×7 雾图，行程 10 房后开祭坛 Boss
3. **战斗**：抽 4 张；你的行动力 = 速度 S × d3（0/1/2 骰面）
4. **胜利**：削韧性 → 破韧奖励 → 引怪踩陷阱 / 砸击；**Boss** 还可熄灭全部信号锚通关
5. **失败**：任意战斗失败即终局；Boss 另有「播出进度满」失败

难度曲线现为 `1→1→2→3→2→5`（前两场保底档 1）；Boss 拆信号 **2** 行动力，熄锚回播出 **−2**。

## 节奏与事件考验（下一轮）

当前问题：惊吓房偏多，静室多为弹窗二选一，节奏容易「一路打到死」。

目标行程混合（可调）：

| 类型 | 约占比 | 作用 |
| --- | --- | --- |
| 惊吓战斗 | 40% | 主循环：放置 × 走位 |
| 静室数值 / 预兆 | 35% | 成长与喘息 |
| **解密 · 视角事件** | 25% | 山屋惊魂式「事件考验」，调剂操作通道 |

计划中的缝合小玩法（**不替代**主战斗）：

**身份锚点**：正式名《织梦频道 channel dream》（简称 channel）。我们是**怀旧邪典荒诞**的儿童节目外壳（*Superjail* 那种失控感），走进山屋（Haunt 式事件考验）——**不是**马里奥派对。小玩法是节拍器与调剂，**克制用量**；主循环永远是放置 × 走位与构筑。


调剂原则：不在于多复杂，而要**足够有趣**；允许一点「年代记忆」玩具感（跟键、盒中景、滑块），失败可以惨但不一定死局。

1. **QTE 占位（已接）**：限时跟键——有意保留一点「打字通关」的憨；`eventType: "qte"` 静室先进考验再发奖；失败丢奖励，血>1 时 −1。全图目前只挂泥靴间，**不要**再批量铺开
2. **八数码拼图**：滑块还原；限步/限时；成功给遗物/牌等，失败多为丢奖励
3. **第二视角搜物房**（最终 3D 微缩景深，非扁横版）：限时找小道具；调剂操作通道，不是第二成长轴
4. **以后（旁支，非本切片目标）**：金山打字「警察抓小偷」式联机——谁打字快谁跑得快——可作 **PvP 小游戏/派对模式** 素材；**不进**山屋单机主线的核心定位

小游戏只挂在少数 `combat:false` 或 `eventType`（目前仅 `mudroom` = `qte`）；主战斗仍是放置走位。

## Boss 仪式

- 双轨：熄灭全部锚点 **或** 打空血条
- 播出进度条满 = 被播映失败；躲墙、熄锚、破韧可减速
- 蓄力回合虚线红格；引它砸地可砸灭锚点
- 公开节目指令每敌回合刷新

## 地图与战斗

- 20+ 房间，每间独立战场：墙、高低差、部分房有传送格（西厢 / 长廊 / 地窖）
- 墙挡视线 → 转角**突脸**；无视线时敌人搜索 `lastSeen`
- 上高台可藏匿 / 高打低；攀爬额外耗行动力（遗物「胶靴」免攀爬）
- **意图看格子**：红格 = 会受伤；`2×2` = 两段共 4；`→` 后为格挡后实伤；蓝虚线 = 它下一步
- **多段攻击**：默认单段；带「连击」词条的怪（阁楼 / 地窖）一回合多段，红字写清段数；Boss 多段改由蓄力承担
- **空间连击**：盐道 / 闪瞎 / 夹击 / 纸影 / 追击踩踏 / 高台砸击 / 隧道

## 卡牌类型

| 类型 | 用法 |
| --- | --- |
| 放置 | 点选后放邻格，或有视线时砸敌人脚下 |
| 技巧 | 点一下立刻生效（护身符 +2 格挡、推撞、屏息等），**不用放置** |
| 药物 | 点一下立刻生效（补剂 / 肾上腺素），可被偷 |

「保留」= 未打出时回合结束留在手牌；**留在手里不会自动挡伤**，要挡伤必须点出去。盐圈是走位防御：站上去才吃格挡。

## 成长

- **牌库为主**：战斗胜利 2 选 1 加牌
- **遗物节点**：开局二选一、中点（已结算 ≥4 房）下一静室保底一枚
- **数值为辅**：静室每次两选，速度出现率较低
- 玄关只是出发格，不再发第二份奖励

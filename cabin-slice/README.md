# 织梦频道 channel dream · 山屋切片（Run Scheme v3）

正式名 **《织梦频道 channel dream》**（简称 **channel**）。本目录是仓库里的可玩竖切片。

协作总览、文档索引、多人约定：仓库根 [README.md](../README.md)、[CONTRIBUTING.md](../CONTRIBUTING.md)。

**美学**：怀旧邪典荒诞——儿童节目外壳、失控的超现实内核（气质接近 *Superjail*）；山屋惊魂式考验，不是派对合集。

与杀戮尖塔的核心差异：**出牌 = 往场地放物品；移动迫使敌人把行动力花在追击上**，而不是站桩结算。

## 运行

想要一键启动：

- macOS：双击 `一键启动.command`
- Windows：双击 `一键启动.bat`

脚本会启动本地网页服务并自动打开浏览器；关闭终端窗口即可停止服务。

```bash
cd cabin-slice
python3 -m http.server 8787
```

浏览器打开：http://127.0.0.1:8787/

- 存档键 `cabin-run-v3`（进行中的一局；分出胜负即清除）
- **实验记录** `cabin-lab-v1`：每场战斗的胜负、回合、输出/受伤、破韧、连击、牌库与遗物快照会保留，标题页可导出 JSON（最多 40 场）
- 自测脚本：`scripts/boss_selftest.py`、`scripts/full_selftest.py`（需 Playwright）

新开一局请点「打开电视机」。没玩过可用「新手教学」（与正式局同一流程：盖屋 → 进门 → 开战，含放置 / 看格 / 预备甩开）。调试入口提供「测预备·甩开」、Boss、WASD、QTE 等沙盒。

## 桌面版（Windows 单机 exe）

- **分发包**：仓库根 `CabinSlice_织梦频道_Windows.zip`（双击 exe 即玩，内嵌全部资源，无需安装 / 联网）
- **源码**：`desktop/launcher/`（Go 启动器：内嵌 web → 本地 127.0.0.1:17887 → 自动开浏览器）+ `desktop/build.sh`
- **重新打包**（macOS 上，需 Go 1.21+）：

```bash
cd cabin-slice && ./desktop/build.sh
```

> 端口被占自动顺延；关掉控制台窗口即退出服务；首次运行如遇 SmartScreen，点「更多信息」→「仍要运行」。

## 一局怎么玩

1. **开局**：行前预兆二选一（8 枚遗物池）；起手生命 **6**，并携带 **护身符**（即时格挡）
2. **探索**：6×7 雾图，探索 10 房后进入祭坛 Boss 战
3. **战斗**：每回合抽 4 张牌；你的行动力 = 速度 S × d3（0/1/2 骰面）
4. **胜利**：削韧性 → 破韧奖励 → 引怪踩陷阱 / 砸击；Boss 战还可通过熄灭全部信号锚通关
5. **失败**：任意战斗失败即终局；Boss 战另有「播出进度满」这一失败条件

难度曲线现为 `1→2→2→3→3→3`（第 2 场起加压；档 3 伤 +1）；Boss 战中拆信号耗 **1** 行动力；每熄一锚，播出进度 **−2**，播出上限 **14**（熄 1 锚后「换台」时钟加快；「加播」要拆掉 2 锚后才进池）。

## 节奏与事件考验

目标行程配比（开局平面图按种子分配 `runRole`，约 **惊吓 40% / 静室 35% / 事件 25%**；玄关固定为静室；⚠️ 配比仍在研究中，尚未精确校准）：

| 类型 | 约占比 | 作用 |
| --- | --- | --- |
| 惊吓战斗 | 40% | 主循环：放置 × 走位 |
| 静室数值 / 预兆 | 35% | 成长与喘息 |
| 解密 · 视角事件 | 25% | 山屋惊魂式「事件考验」，调剂节奏（会客室拼图 / 泥靴间 QTE；亦可改配到其它房） |

事件类型池目前复用 `qte` / `puzzle`（见 `layoutRoll.eventTypes`）。小游戏是节拍器，**不替代**主战斗。

## Boss 仪式

- 双轨：熄灭全部锚点 **或** 打空血条
- 播出进度条满 = 被播映失败；躲墙、熄锚、破韧可减速
- 蓄力回合显示虚线红格；引它砸地可砸灭锚点
- 公开节目指令每敌回合刷新
- Boss 库（`data/bosses.json`，7 名）：原创 4 名 + 从《山屋惊魂》剧本库改编 3 名——疯狂导演（《导演加长版》）、躲猫猫小姐（《鬼抓人》）、星位司仪（《众星就位》），按前段/后段战斗指纹收束分配

## 地图与战斗

- 20+ 房间，每间独立战场：墙、高低差、部分房有传送格（西厢 / 长廊 / 地窖）
- 墙挡视线 → 转角**突脸**；无视线时敌人搜索 `lastSeen`
- 上高台可藏匿 / 高打低；攀爬额外耗行动力（遗物「胶靴」免攀爬）
- **意图看格子**：红格 = 会受伤；`2×2` = 两段共 4；`→` 后为格挡后实伤；蓝虚线 = 它的下一步
- **多段攻击**：默认单段；带「连击」词条的怪（阁楼 / 地窖）一回合多段，红字写清段数；Boss 多段改由蓄力承担
- **空间连击**：盐道 / 闪瞎 / 夹击 / 纸影 / 追击踩踏 / 高台砸击 / 隧道

## 卡牌类型

| 类型 | 用法 |
| --- | --- |
| 放置 | 点选后放邻格，或有视线时砸敌人脚下 |
| 技巧 | 点一下立刻生效（护身符 +2 格挡、推撞、屏息等），**不用放置** |
| 药物 | 点一下立刻生效（补剂 / 肾上腺素），可被偷 |

「保留」= 未打出时回合结束留在手牌；**留在手里不会自动挡伤**，要格挡伤害必须把牌打出去。盐圈是走位防御：站上去才吃格挡。

## 成长

- **现行**：牌库为主（战后 2 选 1）+ 遗物节点 + 静室小数值；玄关只作出发点、不再发第二份奖励
- **存疑**：牌库构筑可能让位于能力值系统 —— 先讨论并写回 [docs/open-questions.md](../docs/open-questions.md)，勿直接拆构筑

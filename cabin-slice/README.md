# Dream Channel · 山屋频道（Run Scheme v3）

与杀戮尖塔的核心差异：**出牌 = 往场地放物品；移动迫使敌人把体力花在追击上**，而不是站桩结算。

## 运行

```bash
cd cabin-slice
python3 -m http.server 8787
```

http://127.0.0.1:8787/ （需重新「开机」，存档键 `cabin-run-v3`）

## 地图与战斗

- 山屋约 20+ 房间（6×7 雾图）；行程仍 10，路线选择更多
- **每间房战场**：尺寸 + **遮挡墙** + **高低差**
- 墙挡视线 → 转角可能**突脸**；无视线时敌人只搜索上次目击点
- 上高台可藏匿/高打低；攀爬额外耗体
- 体力 S·d3；移动/放置；敌人会踩陷阱追击
